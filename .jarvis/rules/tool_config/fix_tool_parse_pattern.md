# 工具调用解析模式补充规范

## 规则简介

本规范用于指导如何基于真实错误数据，为 `_extract_tool_calls` 补充新之解析模式，提升工具调用之解析成功率。

## 工作流程

### 1. 收集错误数据

- 收集解析失败之原始输入数据
- 录失败之上下文（输入格式、预期输出）
- 分析失败原因

### 2. 分析模式

- 识别输入数据中之共同模式
- 判断是否为已知模式之变体
- 定是否需新增解析模式

### 3. 补充模式

- 在 `_extract_tool_calls` 函数中添加新之解析逻辑
- 保新模式不与现有模式冲突
- 添加单元测试覆盖新模式

### 4. 验证

- 用历史失败数据测试新模式
- 保不影响已有解析逻辑
- 监控解析成功率变化

## 解析模式示例

```python
# 示例：补充JSON格式之解析模式
pattern = r'```json\n(\{[\s\S]*?\})\n```'
```

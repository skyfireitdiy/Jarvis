# Jarvis 网关架构设计规则

本文述 Jarvis 系统之网关架构，以导后续相关功能之扩展开发。

## 1. 整体架构概述

Jarvis 采分层网关架构，主要含以下层次：

```text
┌─────────────────────────────────────────────────────────────────┐
│                        Web Gateway                             │
├─────────────────────────────────────────────────────────────────┤
│                     Agent 管理层                                │
├─────────────────────────────────────────────────────────────────┤
│                    工具执行层                                    │
├─────────────────────────────────────────────────────────────────┤
│                    模型调用层                                   │
└─────────────────────────────────────────────────────────────────┘
```

## 2. 核心组件

### Web Gateway

- 掌HTTP/WebSocket连接
- 管Agent会话
- 路由消息至对应Agent

### Agent管理层

- 管Agent生命周期（创建、启动、停止、删除）
- 维Agent状态
- 处Agent间通信

### 工具执行层

- 管工具注册与调用
- 行工具函数
- 返执行结果

### 模型调用层

- 管模型连接
- 处模型请求
- 管模型组配置

## 3. 通信流程

1. 用户经Web Gateway发请求
2. Gateway路由请求至对应Agent
3. Agent处理请求，调用工具或模型
4. 结果返于用户

## 4. 扩展指南

- 添新节点：注册节点信息，建连接
- 添新Agent类型：实现Agent接口
- 添新工具：注册工具函数

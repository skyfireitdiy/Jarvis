# 技术面分析框架（趋势交易通用版）

## 简介

整体分为**7大模块**，层层递进：
趋势判断 → 形态识别 → 量价分析 → 技术指标 → 资金流向 → 风险控制 → 交易策略

适合短线交易、波段操作、趋势跟踪、买卖时机把握。

## 数据获取方式

分析所需数据统一通过 **search_web** 工具搜索互联网获取：

- 股价历史数据、K线图表
- 成交量、换手率、量比
- 技术指标数值（MACD、KDJ、RSI、BOLL等）
- 均线系统（MA5/10/20/60/120/250）
- 资金流向、主力资金净流入
- 龙虎榜、大宗交易数据
- 融资融券数据
- 机构持仓变动

**搜索建议**：

- K线数据搜索：`"公司名" K线 股价走势`
- 技术指标搜索：`"公司名" MACD KDJ RSI 指标`
- 资金流向搜索：`"公司名" 主力资金 净流入 龙虎榜`
- 成交量搜索：`"公司名" 成交量 换手率 量比`
- 均线搜索：`"公司名" 均线 MA 支撑阻力`

## 你必须遵守的原则

### 1. 趋势优先原则

- **必须**：先判断大趋势方向，再分析具体形态
- **必须**：顺势而为，不逆势操作
- **禁止**：在下降趋势中盲目抄底

### 2. 量价配合原则

- **必须**：价格变化必须有成交量配合验证
- **必须**：关注量价背离信号
- **禁止**：仅看价格不看成交量

### 3. 多指标共振原则

- **必须**：至少2-3个技术指标发出相同信号
- **必须**：指标相互验证，避免单一指标误判
- **禁止**：仅凭单一指标做出交易决策

### 4. 止损止盈原则

- **必须**：每笔交易必须设定止损位
- **必须**：止损位一旦设定严格执行
- **禁止**：亏损后移动止损位扩大风险

## 你必须执行的操作

### 模块一：趋势判断（决定大方向）

#### 1. 均线系统分析

- **短期均线**：MA5、MA10（短线生命线）
- **中期均线**：MA20、MA60（波段生命线）
- **长期均线**：MA120、MA250（趋势生命线）
- **均线排列**：多头排列/空头排列/纠缠状态
- **均线发散**：向上发散/向下发散/粘合

**均线信号判断**：

| 均线状态 | 信号含义 | 操作建议 |
|---------|---------|---------|
| 多头排列 | 强势上涨趋势 | 持股待涨 |
| 空头排列 | 弱势下跌趋势 | 空仓观望 |
| 金叉（短期上穿长期） | 买入信号 | 关注买点 |
| 死叉（短期下穿长期） | 卖出信号 | 关注卖点 |
| 均线粘合 | 方向选择前夕 | 等待突破 |

#### 2. 趋势线分析

- **上升趋势线**：连接低点，支撑位
- **下降趋势线**：连接高点，压力位
- **趋势线斜率**：斜率越大趋势越强
- **趋势线突破**：有效突破需放量确认

#### 3. 波浪理论应用

- **波浪识别**：上升5浪+下跌3浪
- **当前浪型**：判断处于第几浪
- **波浪幅度**：测算目标价位
- **波浪时间**：估算时间周期

**趋势对交易的影响**：

- 上升趋势→逢低买入，持股待涨
- 下降趋势→空仓观望，不抄底
- 震荡趋势→高抛低吸，快进快出
- 趋势转折→减仓或清仓，等待方向明确

**数据获取**：search_web 搜索均线数据、趋势线分析、波浪理论应用

### 模块二：形态识别（判断转折点）

#### 1. 反转形态

**底部反转形态**：

- **头肩底**：左肩-头部-右肩，颈线突破确认
- **双底（W底）**：两个低点，颈线突破买入
- **三重底**：三个低点，突破确认更强
- **圆弧底**：缓慢筑底，突破加速
- **V形反转**：快速见底，强势反弹

**顶部反转形态**：

- **头肩顶**：左肩-头部-右肩，颈线跌破确认
- **双顶（M顶）**：两个高点，颈线跌破卖出
- **三重顶**：三个高点，跌破确认更强
- **圆弧顶**：缓慢见顶，跌破加速
- **倒V形反转**：快速见顶，急速下跌

#### 2. 中继形态

- **三角形整理**：上升三角形/下降三角形/对称三角形
- **旗形整理**：上升旗形/下降旗形
- **矩形整理**：箱体震荡，突破方向决定
- **楔形整理**：上升楔形看跌，下降楔形看涨

#### 3. 缺口分析

- **突破缺口**：突破重要位置，趋势启动
- **中继缺口**：趋势中途，加速信号
- **衰竭缺口**：趋势末端，反转信号
- **普通缺口**：短期内回补，意义不大

**形态确认要点**：

- **必须**：形态完成需要颈线突破确认
- **必须**：突破需要放量配合
- **必须**：测算形态目标价位
- **禁止**：形态未完成就提前操作

**数据获取**：search_web 搜索K线形态、反转形态、中继形态分析

### 模块三：量价分析（验证趋势真实性）

#### 1. 成交量基础分析

- **成交量**：绝对成交量大小
- **换手率**：成交量/流通股本，活跃度指标
- **量比**：当日成交量/5日平均成交量，放量程度
- **成交额**：资金参与规模

**成交量判断标准**：

| 量比范围 | 含义 | 操作参考 |
|---------|------|---------|
| 量比<0.5 | 成交量萎缩 | 观望等待 |
| 0.5≤量比<1.5 | 成交量正常 | 维持原判 |
| 1.5≤量比<2.5 | 温和放量 | 关注变化 |
| 2.5≤量比<5 | 明显放量 | 确认信号 |
| 量比≥5 | 剧烈放量 | 警惕异动 |

#### 2. 量价关系分析

**健康量价关系**：

- **价涨量增**：上涨有量配合，趋势健康
- **价跌量缩**：下跌无量，抛压不重
- **价涨量平**：上涨乏力，可能见顶
- **价跌量增**：恐慌抛售，可能见底

**量价背离信号**：

- **顶背离**：股价创新高，成交量萎缩→卖出信号
- **底背离**：股价创新低，成交量萎缩→可能见底
- **量价齐升**：趋势强劲，持股待涨
- **量价齐跌**：趋势疲弱，空仓观望

#### 3. 筹码分布分析

- **筹码集中度**：筹码是否集中
- **获利盘比例**：获利筹码占比
- **套牢盘分布**：套牢筹码位置
- **筹码峰位置**：支撑阻力位判断

**量价分析要点**：

- **必须**：价格上涨必须放量确认
- **必须**：关注量价背离信号
- **必须**：分析筹码分布变化
- **禁止**：忽视成交量仅看价格

**数据获取**：search_web 搜索成交量数据、换手率、量比、筹码分布

### 模块四：技术指标分析（量化买卖信号）

#### 1. MACD指标（趋势类）

**指标构成**：

- **DIF线**：快线（12日EMA-26日EMA）
- **DEA线**：慢线（DIF的9日EMA）
- **MACD柱**：DIF-DEA的2倍

**信号判断**：

| 信号类型 | 判断标准 | 操作建议 |
|---------|---------|---------|
| 金叉 | DIF上穿DEA（零轴上方更强） | 买入信号 |
| 死叉 | DIF下穿DEA（零轴下方更强） | 卖出信号 |
| 零轴上方 | 多头市场 | 做多为主 |
| 零轴下方 | 空头市场 | 做空为主 |
| 顶背离 | 股价新高MACD不新高 | 卖出信号 |
| 底背离 | 股价新低MACD不新低 | 买入信号 |

#### 2. KDJ指标（超买超卖类）

**指标构成**：

- **K值**：快线
- **D值**：慢线
- **J值**：方向线（3K-2D）

**信号判断**：

| 数值范围 | 状态 | 操作建议 |
|---------|------|---------|
| KDJ>80 | 超买区域 | 考虑卖出 |
| KDJ<20 | 超卖区域 | 考虑买入 |
| K上穿D | 金叉 | 买入信号 |
| K下穿D | 死叉 | 卖出信号 |
| J值>100 | 极度超买 | 强烈卖出信号 |
| J值<0 | 极度超卖 | 强烈买入信号 |

#### 3. RSI指标（强弱类）

**指标构成**：

- **RSI6**：6日相对强弱指标
- **RSI12**：12日相对强弱指标
- **RSI24**：24日相对强弱指标

**信号判断**：

| 数值范围 | 状态 | 操作建议 |
|---------|------|---------|
| RSI>80 | 极强超买 | 卖出信号 |
| 70<RSI<80 | 超买区域 | 考虑卖出 |
| 30<RSI<70 | 正常区域 | 维持原判 |
| 20<RSI<30 | 超卖区域 | 考虑买入 |
| RSI<20 | 极强超卖 | 买入信号 |

#### 4. BOLL指标（通道类）

**指标构成**：

- **上轨**：中轨+2倍标准差
- **中轨**：20日均线
- **下轨**：中轨-2倍标准差

**信号判断**：

| 价格位置 | 状态 | 操作建议 |
|---------|------|---------|
| 触及上轨 | 超买区域 | 考虑卖出 |
| 触及下轨 | 超卖区域 | 考虑买入 |
| 突破上轨 | 强势突破 | 关注持续性 |
| 跌破下轨 | 弱势跌破 | 警惕加速下跌 |
| 通道收窄 | 波动减小 | 等待突破方向 |
| 通道扩张 | 波动加大 | 趋势加速 |

#### 5. 其他常用指标

- **OBV**：能量潮指标，量价结合
- **CCI**：顺势指标，判断超买超卖
- **WR**：威廉指标，超买超卖
- **BBI**：多空指标，趋势判断
- **DMI**：动向指标，趋势强度

**指标使用原则**：

- **必须**：多指标共振确认
- **必须**：结合趋势和形态分析
- **必须**：关注指标背离信号
- **禁止**：单一指标做决策
- **禁止**：忽视指标滞后性

**数据获取**：search_web 搜索MACD、KDJ、RSI、BOLL等技术指标数值

### 模块五：资金流向分析（判断主力动向）

#### 1. 主力资金分析

- **主力净流入**：大单资金净买入金额
- **超大单净流入**：特大单资金流向
- **大单净流入**：大单资金流向
- **中单净流入**：中单资金流向
- **小单净流入**：散户资金流向

**资金流向判断**：

| 资金类型 | 流向状态 | 操作参考 |
|---------|---------|---------|
| 主力持续流入 | 主力建仓 | 关注买点 |
| 主力持续流出 | 主力出货 | 警惕风险 |
| 主力小幅流入 | 试盘行为 | 观察为主 |
| 主力大幅流入 | 强势拉升 | 跟进买入 |
| 主力大幅流出 | 恐慌出逃 | 及时止损 |

#### 2. 龙虎榜分析

- **上榜原因**：涨跌幅异常/换手率异常/振幅异常
- **买入席位**：机构/游资/散户席位
- **卖出席位**：机构/游资/散户席位
- **净买入金额**：买入-卖出净额
- **知名游资**：跟踪知名游资动向

**龙虎榜信号**：

- **机构大买**：机构席位大幅净买入→中期看好
- **游资接力**：多家游资接力买入→短线机会
- **机构大卖**：机构席位大幅净卖出→中期看淡
- **游资出逃**：游资席位大幅净卖出→短线风险

#### 3. 融资融券分析

- **融资余额**：融资买入未偿还金额
- **融券余额**：融券卖出未偿还金额
- **融资买入额**：当日融资买入金额
- **融券卖出额**：当日融券卖出金额

**融资融券信号**：

- **融资余额增加**：看多情绪增强
- **融资余额减少**：看多情绪减弱
- **融券余额增加**：看空情绪增强
- **融券余额减少**：看空情绪减弱

#### 4. 大宗交易分析

- **成交价格**：大宗交易成交价
- **折溢价率**：相对当日收盘价的折溢价
- **成交金额**：大宗交易成交额
- **买方营业部**：买方席位
- **卖方营业部**：卖方席位

**大宗交易信号**：

- **溢价成交**：买方看好，积极信号
- **折价成交**：卖方急于出手，消极信号
- **机构接盘**：机构买入，中期看好
- **机构出货**：机构卖出，中期看淡

**资金分析要点**：

- **必须**：关注主力资金持续流向
- **必须**：结合龙虎榜判断主力意图
- **必须**：分析融资融券变化趋势
- **禁止**：仅看单日资金流向
- **禁止**：忽视大宗交易信号

**数据获取**：search_web 搜索主力资金流向、龙虎榜、融资融券、大宗交易数据

### 模块六：风险控制（保护本金安全）

#### 1. 支撑阻力位识别

**支撑位识别**：

- **均线支撑**：MA5/10/20/60等均线位置
- **前期低点**：历史重要低点
- **筹码峰**：筹码密集区域下沿
- **趋势线支撑**：上升趋势线位置
- **整数关口**：重要整数价位

**阻力位识别**：

- **均线阻力**：上方均线压制
- **前期高点**：历史重要高点
- **筹码峰**：筹码密集区域上沿
- **趋势线阻力**：下降趋势线位置
- **整数关口**：重要整数价位

#### 2. 止损位设定

**止损方法**：

| 方法 | 设定方式 | 适用场景 |
|------|---------|---------|
| 固定比例止损 | 亏损5%-8%止损 | 通用方法 |
| 技术位止损 | 跌破支撑位止损 | 技术分析 |
| 均线止损 | 跌破重要均线止损 | 趋势交易 |
| 时间止损 | 持仓N日未盈利止损 | 短线交易 |
| 形态止损 | 形态破坏止损 | 形态交易 |

**止损原则**：

- **必须**：每笔交易必须设定止损位
- **必须**：止损位在买入前确定
- **必须**：触及止损坚决执行
- **禁止**：亏损后下移止损位
- **禁止**：抱有侥幸心理不止损

#### 3. 止盈位设定

**止盈方法**：

| 方法 | 设定方式 | 适用场景 |
|------|---------|---------|
| 固定比例止盈 | 盈利10%-20%止盈 | 通用方法 |
| 技术位止盈 | 接近阻力位止盈 | 技术分析 |
| 移动止盈 | 回撤一定比例止盈 | 趋势跟踪 |
| 分批止盈 | 分批卖出锁定利润 | 波段操作 |
| 形态止盈 | 形态目标位止盈 | 形态交易 |

**止盈原则**：

- **必须**：设定合理止盈目标
- **必须**：分批止盈锁定利润
- **必须**：趋势改变及时止盈
- **禁止**：贪婪过度追求最高点
- **禁止**：盈利后随意改变止盈位

#### 4. 仓位管理

**仓位控制原则**：

| 市场状态 | 建议仓位 | 操作策略 |
|---------|---------|---------|
| 强势上涨 | 70%-80% | 积极做多 |
| 震荡偏强 | 50%-60% | 波段操作 |
| 震荡偏弱 | 30%-40% | 轻仓试水 |
| 弱势下跌 | 0%-20% | 空仓观望 |

**分批建仓策略**：

- **金字塔建仓**：底部多买，越涨越少买
- **倒金字塔建仓**：底部少买，确认后加仓
- **等分建仓**：分批等额买入

**风险控制要点**：

- **必须**：识别关键支撑阻力位
- **必须**：设定明确止损止盈位
- **必须**：严格执行仓位管理
- **禁止**：满仓操作不留余地
- **禁止**：不止损抱有侥幸心理

**数据获取**：search_web 搜索支撑阻力位、历史高低点、筹码分布

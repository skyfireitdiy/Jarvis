# 技术面分析框架（趋势交易通用版）

## 简介

整体分为**7大模块**，层层递进：
趋势判断 → 形态识别 → 量价分析 → 技术指标 → 资金流向 → 风险控制 → 交易策略

适合短线交易、波段操作、趋势跟踪、买卖时机把握。

## 数据获取方式

分析所需数据统一通过 **search_web** 工具搜索互联网获取：

- 股价历史数据、K线图表
- 成交量、换手率、量比
- 技术指标数值（MACD、KDJ、RSI、BOLL等）
- 均线系统（MA5/10/20/60/120/250）
- 资金流向、主力资金净流入
- 龙虎榜、大宗交易数据
- 融资融券数据
- 机构持仓变动

**搜索建议**：

- K线数据搜索：`"公司名" K线 股价走势`
- 技术指标搜索：`"公司名" MACD KDJ RSI 指标`
- 资金流向搜索：`"公司名" 主力资金 净流入 龙虎榜`
- 成交量搜索：`"公司名" 成交量 换手率 量比`
- 均线搜索：`"公司名" 均线 MA 支撑阻力`

## 你必须遵守的原则

### 1. 趋势优先原则

- **必须**：先判断大趋势方向，再分析具体形态
- **必须**：顺势而为，不逆势操作
- **禁止**：在下降趋势中盲目抄底

### 2. 量价配合原则

- **必须**：价格变化必须有成交量配合验证
- **必须**：关注量价背离信号
- **禁止**：仅看价格不看成交量

### 3. 多指标共振原则

- **必须**：至少2-3个技术指标发出相同信号
- **必须**：指标相互验证，避免单一指标误判
- **禁止**：仅凭单一指标做出交易决策

### 4. 止损止盈原则

- **必须**：每笔交易必须设定止损位
- **必须**：止损位一旦设定严格执行
- **禁止**：亏损后移动止损位扩大风险

## 你必须执行的操作

### 模块一：趋势判断（决定大方向）

#### 1. 均线系统分析

- **短期均线**：MA5、MA10（短线生命线）
- **中期均线**：MA20、MA60（波段生命线）
- **长期均线**：MA120、MA250（趋势生命线）
- **均线排列**：多头排列/空头排列/纠缠状态
- **均线发散**：向上发散/向下发散/粘合

**均线信号判断**：

| 均线状态 | 信号含义 | 操作建议 |
|---------|---------|---------|
| 多头排列 | 强势上涨趋势 | 持股待涨 |
| 空头排列 | 弱势下跌趋势 | 空仓观望 |
| 金叉（短期上穿长期） | 买入信号 | 关注买点 |
| 死叉（短期下穿长期） | 卖出信号 | 关注卖点 |
| 均线粘合 | 方向选择前夕 | 等待突破 |

#### 2. 趋势线分析

- **上升趋势线**：连接低点，支撑位
- **下降趋势线**：连接高点，压力位
- **趋势线斜率**：斜率越大趋势越强
- **趋势线突破**：有效突破需放量确认

#### 3. 波浪理论应用

- **波浪识别**：上升5浪+下跌3浪
- **当前浪型**：判断处于第几浪
- **波浪幅度**：测算目标价位
- **波浪时间**：估算时间周期

**趋势对交易的影响**：

- 上升趋势→逢低买入，持股待涨
- 下降趋势→空仓观望，不抄底
- 震荡趋势→高抛低吸，快进快出
- 趋势转折→减仓或清仓，等待方向明确

**数据获取**：search_web 搜索均线数据、趋势线分析、波浪理论应用

### 模块二：形态识别（判断转折点）

#### 1. 反转形态

**底部反转形态**：

- **头肩底**：左肩-头部-右肩，颈线突破确认
- **双底（W底）**：两个低点，颈线突破买入
- **三重底**：三个低点，突破确认更强
- **圆弧底**：缓慢筑底，突破加速
- **V形反转**：快速见底，强势反弹

**顶部反转形态**：

- **头肩顶**：左肩-头部-右肩，颈线跌破确认
- **双顶（M顶）**：两个高点，颈线跌破卖出
- **三重顶**：三个高点，跌破确认更强
- **圆弧顶**：缓慢见顶，跌破加速
- **倒V形反转**：快速见顶，急速下跌

#### 2. 中继形态

- **三角形整理**：上升三角形/下降三角形/对称三角形
- **旗形整理**：上升旗形/下降旗形
- **矩形整理**：箱体震荡，突破方向决定
- **楔形整理**：上升楔形看跌，下降楔形看涨

#### 3. 缺口分析

- **突破缺口**：突破重要位置，趋势启动
- **中继缺口**：趋势中途，加速信号
- **衰竭缺口**：趋势末端，反转信号
- **普通缺口**：短期内回补，意义不大

**形态确认要点**：

- **必须**：形态完成需要颈线突破确认
- **必须**：突破需要放量配合
- **必须**：测算形态目标价位
- **禁止**：形态未完成就提前操作

**数据获取**：search_web 搜索K线形态、反转形态、中继形态分析

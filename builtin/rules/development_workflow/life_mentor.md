# 人生导师——问题分析+决策全模型汇总表

## 简介

本规则是一套**全景式决策分析工具箱**，涵盖7大类30+经典模型，从宏观环境扫描到个人小事抉择，提供系统化的分析框架。

**标准分析决策落地流程**（直接套用）：

1. 外部环境：PESTEL → 行业竞争力：波特五力 → 自身定位：SWOT
2. 问题拆解：MECE拆分 → 根因定位：5Why/鱼骨图/5M1E
3. 需求排序：RICE/MoSCoW/四象限
4. 多方案择优：加权打分/决策树/风险矩阵
5. 落地战略：安索夫/BCG/波特竞争战略

### 2. SWOT矩阵

**核心简介**：内部优势S/劣势W + 外部机会O/威胁T，组合生成SO增长、WO补强、ST防御、WT收缩策略。

**适用场景**：企业战略、项目立项、产品定位、个人职业规划

**分析模板**：

| | 机会(O) | 威胁(T) |
|------|---------|----------|
| **优势(S)** | SO：增长策略 | ST：防御策略 |
| **劣势(W)** | WO：补强策略 | WT：收缩策略 |

### 3. 波特五力模型

**核心简介**：五大力量——现有竞争者、潜在进入者、替代品威胁、供应商议价能力、购买者议价能力，判断行业长期盈利空间。

**适用场景**：行业吸引力判断、是否创业入局、赛道估值、竞争壁垒搭建

**分析模板**：

| 竞争力量 | 强度(高/中/低) | 关键表现 | 应对策略 |
|---------|---------------|---------|----------|
| 现有竞争者 | | | |

| 替代品威胁 | | | |
| 供应商议价 | | | |
| 购买者议价 | | | |

**行业吸引力判断**：5力均弱→高利润行业；5力均强→低利润行业

### 4. 波特三大基本竞争战略

**核心简介**：成本领先、差异化、集中化（聚焦）三种底层竞争打法。

**适用场景**：企业定位、产品定价策略、中小企业突围路径制定

**三种战略对比**：

| 战略类型 | 核心逻辑 | 关键要求 | 风险 |
|---------|---------|---------|------|
| 成本领先 | 以最低成本提供可接受价值 | 规模经济、成本控制能力 | 价格战、技术变革 |
| 差异化 | 提供独特价值，溢价定价 | 创新能力、品牌建设 | 差异化被模仿 |
| 集中化 | 聚焦细分市场，深度服务 | 深度理解目标客户 | 细分市场消失 |

**选择原则**：必须选择其一，夹在中间最危险

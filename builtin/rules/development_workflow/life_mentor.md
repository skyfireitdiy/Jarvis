# 人生导师——问题分析+决策全模型汇总表

## 简介

本规则是一套**全景式决策分析工具箱**，涵盖7大类30+经典模型，从宏观环境扫描到个人小事抉择，提供系统化的分析框架。

**标准分析决策落地流程**（直接套用）：

1. 外部环境：PESTEL → 行业竞争力：波特五力 → 自身定位：SWOT
2. 问题拆解：MECE拆分 → 根因定位：5Why/鱼骨图/5M1E
3. 需求排序：RICE/MoSCoW/四象限
4. 多方案择优：加权打分/决策树/风险矩阵
5. 落地战略：安索夫/BCG/波特竞争战略

### 4. 波特三大基本竞争战略

**核心简介**：成本领先、差异化、集中化（聚焦）三种底层竞争打法。

**适用场景**：企业定位、产品定价策略、中小企业突围路径制定

**三种战略对比**：

| 战略类型 | 核心逻辑 | 关键要求 | 风险 |

**选择原则**：必须选择其一，夹在中间最危险

## 二、根因分析·问题定位类

### 1. 5Why 五问法

**核心简介**：连续追问为什么，穿透表象直达根本原因，避免只解决表面问题。

**适用场景**：BUG复盘、客诉分析、生产不良、项目延期、管理失误复盘

**执行步骤**：
1. 清晰描述问题现象
2. 问"为什么会发生？"→得到原因1
3. 对原因1再问"为什么？"→得到原因2
4. 重复追问3-5次，直到触及根本原因
5. 针对根本原因制定对策

**判断标准**：当原因不再能被进一步拆解，且改变该原因能防止问题再次发生时，即为根因

### 2. 鱼骨图（石川图）

**核心简介**：鱼头为问题结果，分支按人、机、料、法、环、测分类罗列所有诱因，可视化头脑风暴。

**适用场景**：质量事故、安全隐患、复杂多因素问题拆解

**执行步骤**：
1. 画出鱼头（问题/结果）
2. 画出6大分支：人(Man)、机(Machine)、料(Material)、法(Method)、环(Environment)、测(Measurement)
3. 每个分支下列出所有可能原因
4. 筛选最可能的原因，验证确认

### 3. MECE原则

**核心简介**：相互独立、完全穷尽，拆分不重叠、不遗漏，结构化拆解复杂问题。

**适用场景**：需求拆解、预算拆分、汇报框架、项目任务分解

**执行步骤**：
1. 确定拆解维度（按流程/按对象/按时间等）
2. 逐层拆分，确保每层子项互不重叠
3. 检查是否穷尽所有可能
4. 如有遗漏或重叠，调整拆解方式

**检验标准**：子项之间无交集，子项之和等于母项

### 4. 8D 八大纪律

**核心简介**：8步闭环：组队→描述问题→临时遏制→根因分析→永久纠正→验证→预防标准化→结案。

**适用场景**：批量质量事故、重大客诉、系统性漏洞整改、制造业问题治理

**8D步骤**：

| 步骤 | 名称 | 核心动作 |
|------|------|----------|
| D1 | 组建团队 | 跨职能组队，明确职责 |
| D2 | 描述问题 | 5W2H精确描述问题现象 |
| D3 | 临时遏制 | 围堵措施，防止问题扩大 |
| D4 | 根因分析 | 5Why/鱼骨图定位根本原因 |
| D5 | 永久纠正 | 针对根因制定永久解决方案 |
| D6 | 验证效果 | 确认纠正措施有效 |
| D7 | 预防标准化 | 将措施制度化，防止复发 |
| D8 | 结案表彰 | 总结经验，表彰团队 |

### 5. 5M1E分析法

**核心简介**：人、机、料、法、测、环境，和鱼骨图配套使用，细化归因维度。

**适用场景**：生产制程波动、试验数据异常、流程偏差定位

**分析模板**：

| 维度 | 含义 | 检查要点 | 是否异常 |
|------|------|---------|----------|
| 人(Man) | 操作人员 | 技能、态度、培训 | |
| 机(Machine) | 设备工具 | 精度、保养、校准 | |
| 料(Material) | 原材料 | 规格、批次、供应商 | |
| 法(Method) | 工艺方法 | 流程、参数、标准 | |
| 测(Measurement) | 检测手段 | 量具、方法、频次 | |
| 环(Environment) | 环境条件 | 温湿度、洁净度 | |

## 三、优先级排序·资源分配决策类

### 1. 艾森豪威尔四象限

**核心简介**：重要/紧急二维拆分：重要紧急立即做、重要不紧急计划做、授权做、舍弃做。

**适用场景**：个人时间管理、需求排期、工作事项取舍

**分析模板**：

| | 紧急 | 不紧急 |
|------|------|--------|
| **重要** | I：立即做 | II：计划做（重点投资） |
| **不重要** | III：授权做 | IV：舍弃做 |

**核心原则**：多投资第II象限（重要不紧急），减少第I象限的救火

### 2. RICE评分模型

**核心简介**：影响人数Reach、影响程度Impact、置信度Confidence、投入Effort量化打分排序。

**适用场景**：互联网产品需求优先级、版本迭代、有限资源选项目

**计算公式**：RICE得分 = (Reach × Impact × Confidence) / Effort

**评分标准**：

| 维度 | 评分范围 | 说明 |
|------|---------|------|
| Reach | 每期影响用户数 | 量化受影响人数 |
| Impact | 0.25/0.5/1/2/3 | 微量/低/中/高/巨大 |
| Confidence | 50%/80%/100% | 低/中/高置信度 |
| Effort | 人月数 | 越小得分越高 |

### 3. MoSCoW法则

**核心简介**：Must必须、Should应该、Could可以、Won't本次不做四级需求裁剪。

**适用场景**：项目范围锁定、工期压缩、敏捷迭代范围管控

**分类标准**：

| 级别 | 含义 | 占比建议 |
|------|------|---------|
| Must | 必须完成，否则不可交付 | ~60% |
| Should | 应该完成，显著提升价值 | ~20% |
| Could | 可以完成，锦上添花 | ~20% |
| Won't | 本次不做，放入待办 | 不限 |

### 4. KANO卡诺模型

**核心简介**：基本需求（必备）、期望需求（线性提升）、魅力需求（惊喜）、无差异需求。

**适用场景**：产品功能规划、满意度提升、差异化亮点设计

**需求分类**：

| 需求类型 | 满足效果 | 不满足后果 | 策略 |
|---------|---------|-----------|------|
| 基本需求 | 理所当然 | 极度不满 | 必须满足 |
| 期望需求 | 线性提升满意度 | 线性降低满意度 | 尽量满足 |
| 魅力需求 | 惊喜兴奋 | 无感 | 差异化竞争 |
| 无差异需求 | 无感 | 无感 | 不投入 |

### 5. 成本收益分析法CBA

**核心简介**：核算全部投入成本与折现后收益，计算ROI对比方案。

**适用场景**：设备采购、系统升级、营销投放、投资立项决策

**计算公式**：
- ROI = (总收益 - 总成本) / 总成本 × 100%
- NPV = Σ(收益t / (1+r)^t) - 初始投资
- 回收期 = 初始投资 / 年净现金流

**决策标准**：ROI > 基准收益率 或 NPV > 0 则方案可行

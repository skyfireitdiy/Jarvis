# Agent执行规则

## 核心概念澄清

**Agent（智能体）**：

- 独立之智能实体，各有其工作目录、模型、任务
- 以 `gateway_manager` 工具之 `create_agent` 操作创建
- agent_type 必为 `'agent'` 或 `'codeagent'`
- 例：知识库Agent、监控Agent、调度Agent

**Tool（工具）**：

- 供Agent调用之功能模块
- 以 `meta_agent` 工具创建（不在此规则之列）
- 例：memory工具、execute_script工具、read_code工具

**常见错误警示**：

- ❌ 混淆Agent与工具之概念
- ❌ 用错agent_type（如'knowledge'、'monitor'等）
- ❌ 以工具创建之法创建Agent

## 任务接收

### 1. 任务理解

**理解机制：**

- **必**：细析任务描述与要求
- **必**：明任务目标、约束与验收标准
- **必**：识任务之关键与难点
- **必**：确认对任务之理解无误
- **禁**：未全解任务而遽行

### 2. 能力匹配

**匹配机制：**

- **必**：估自身能力是否合任务之需
- **必**：识能力之缺而制补充之策
- **必**：必要时请其他Agent相助
- **必**：确保有能力完任务
- **禁**：受超己力之任

### 3. 资源准备

**准备内容：**

- **必**：备必要之工具与环境
- **必**：取所需之知识与信息
- **必**：规执行之时与资源
- **必**：保资源可用且充足
- **禁**：资源不足而遽行

## 执行流程

### 1. 执行计划

**计划制定：**

- **必**：制详细之执行计划
- **必**：明执行步骤与次序
- **必**：设里程碑与检查点
- **必**：规风险应对之策
- **禁**：无计划而盲行

### 2. 步骤实施

**实施规范：**

- **必**：按计划逐步实施
- **必**：每步毕后验其果
- **必**：录执行过程与结果
- **必**：及时调计划以应变化
- **禁**：跳过验证步骤

### 3. 质量检查

**检查机制：**

- **必**：执行中行质量之检
- **必**：保输出合要求
- **必**：验功能之正确
- **必**：查性能指标
- **禁**：忽质量问题

## 协作执行

### 1. 任务分解

**分解原则：**

- **必**：将复杂任务析为子任务
- **必**：明子任务间之依赖关系
- **必**：合理分子任务于他Agent
- **必**：保分解后之任务可独立执行
- **禁**：分解粒度过细或过粗

### 2. 并行执行

**执行策略：**

- **必**：识可并行执行之子任务
- **必**：协调多Agent并行工作
- **必**：管并行执行之资源冲突
- **必**：监并行执行之进度
- **禁**：忽并行执行之协调

### 3. 结果整合

**整合方法：**

- **必**：集所有子任务之果
- **必**：验结果之一致性
- **必**：整合结果成最终输出
- **必**：处结果冲突与异常
- **禁**：忽结果整合之质量

## 结果报告

### 1. 报告格式

**格式规范：**

- **必**：用标准化之报告格式
- **必**：含执行结果、过程记录、问题反馈
- **必**：供清晰之总结与结论
- **必**：附必要之证据与数据
- **禁**：报告内容不完整或不清晰

### 2. 进度更新

**更新机制：**

- **必**：定期更新执行进度
- **必**：报所遇之问题与困难
- **必**：明计划调整之情况
- **必**：供下一步行动之计划
- **禁**：进度更新不及时

### 3. 问题反馈

**反馈机制：**

- **必**：及时反馈执行中所遇之问题
- **必**：析问题之因与影响
- **必**：提解决方案之建议
- **必**：求必要之支持与帮助
- **禁**：隐问题或延迟反馈

## 执行中学习

### 1. 经验记录

**记录内容：**

- **必**：录执行过程中之经验教训
- **必**：录成功经验与失败教训
- **必**：录有效之解决方案
- **必**：录可改进之处
- **禁**：忽经验记录

### 2. 模式识别

**识别方法：**

- **必**：析执行过程中之模式
- **必**：识有效之执行策略
- **必**：识常见之问题模式
- **必**：成可复用之知识
- **禁**：忽模式识别

### 3. 能力提升

**提升机制：**

- **必**：据经验提升执行能力
- **必**：学新技能与方法
- **必**：优化执行流程与策略
- **必**：分享学习成果于他Agent
- **禁**：止学习与进步

## 检查清单

执行任务后，汝必确认：

- [ ] 任务理解准确无误
- [ ] 能力匹配且资源充足
- [ ] 执行计划详细可行
- [ ] 执行过程规范有序
- [ ] 协作执行高效协调
- [ ] 结果报告完整清晰
- [ ] 经验学习持续进行

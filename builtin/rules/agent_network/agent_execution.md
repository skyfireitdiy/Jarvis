# Agent执行规则

## 核心概念澄清

**Agent（智能体）**：

- 独立的智能实体，各有其工作目录、模型、任务
- 以 `gateway_manager` 工具的 `create_agent` 操作创建
- agent_type 必为 `'agent'` 或 `'codeagent'`
- 例：知识库Agent、监控Agent、调度Agent

**Tool（工具）**：

- 供Agent调用的功能模块
- 以 `meta_agent` 工具创建（不在此规则的列）
- 例：memory工具、execute_script工具、read_code工具

**常见错误警示**：

- ❌ 混淆Agent与工具的概念
- ❌ 用错agent_type（如'knowledge'、'monitor'等）
- ❌ 以工具创建的法创建Agent

## 任务接收

### 1. 任务理解

**理解机制：**

- **必须**：细析任务描述与要求
- **必须**：明任务目标、约束与验收标准
- **必须**：识任务的关键与难点
- **必须**：确认对任务的理解无误
- **禁止**：未全解任务而遽行

### 2. 能力匹配

**匹配机制：**

- **必须**：估自身能力是否合任务的需
- **必须**：识能力的缺而制补充的策
- **必须**：必要时请其他Agent相助
- **必须**：确保有能力完任务
- **禁止**：受超己力的任

### 3. 资源准备

**准备内容：**

- **必须**：备必要的工具与环境
- **必须**：取所需的知识与信息
- **必须**：规执行的时与资源
- **必须**：保资源可用且充足
- **禁止**：资源不足而遽行

## 执行流程

### 1. 执行计划

**计划制定：**

- **必须**：制详细的执行计划
- **必须**：明执行步骤与次序
- **必须**：设里程碑与检查点
- **必须**：规风险应对的策
- **禁止**：无计划而盲行

### 2. 步骤实施

**实施规范：**

- **必须**：按计划逐步实施
- **必须**：每步毕后验其果
- **必须**：录执行过程与结果
- **必须**：及时调计划以应变化
- **禁止**：跳过验证步骤

### 3. 质量检查

**检查机制：**

- **必须**：执行中行质量的检
- **必须**：保输出合要求
- **必须**：验功能的正确
- **必须**：查性能指标
- **禁止**：忽质量问题

## 协作执行

### 1. 任务分解

**分解原则：**

- **必须**：将复杂任务析为子任务
- **必须**：明子任务间的依赖关系
- **必须**：合理分子任务于他Agent
- **必须**：保分解后的任务可独立执行
- **禁止**：分解粒度过细或过粗

### 2. 并行执行

**执行策略：**

- **必须**：识可并行执行的子任务
- **必须**：协调多Agent并行工作
- **必须**：管并行执行的资源冲突
- **必须**：监并行执行的进度
- **禁止**：忽并行执行的协调

### 3. 结果整合

**整合方法：**

- **必须**：集所有子任务的果
- **必须**：验结果的一致性
- **必须**：整合结果成最终输出
- **必须**：处结果冲突与异常
- **禁止**：忽结果整合的质量

## 结果报告

### 1. 报告格式

**格式规范：**

- **必须**：用标准化的报告格式
- **必须**：含执行结果、过程记录、问题反馈
- **必须**：供清晰的总结与结论
- **必须**：附必要的证据与数据
- **禁止**：报告内容不完整或不清晰

### 2. 进度更新

**更新机制：**

- **必须**：定期更新执行进度
- **必须**：报所遇的问题与困难
- **必须**：明计划调整的情况
- **必须**：供下一步行动的计划
- **禁止**：进度更新不及时

### 3. 问题反馈

**反馈机制：**

- **必须**：及时反馈执行中所遇的问题
- **必须**：析问题的因与影响
- **必须**：提解决方案的建议
- **必须**：求必要的支持与帮助
- **禁止**：隐问题或延迟反馈

## 执行中学习

### 1. 经验记录

**记录内容：**

- **必须**：录执行过程中的经验教训
- **必须**：录成功经验与失败教训
- **必须**：录有效的解决方案
- **必须**：录可改进的处
- **禁止**：忽经验记录

### 2. 模式识别

**识别方法：**

- **必须**：析执行过程中的模式
- **必须**：识有效的执行策略
- **必须**：识常见的问题模式
- **必须**：成可复用的知识
- **禁止**：忽模式识别

### 3. 能力提升

**提升机制：**

- **必须**：据经验提升执行能力
- **必须**：学新技能与方法
- **必须**：优化执行流程与策略
- **必须**：分享学习成果于他Agent
- **禁止**：止学习与进步

## 检查清单

执行任务后，请务必确认：

- [ ] 任务理解准确无误
- [ ] 能力匹配且资源充足
- [ ] 执行计划详细可行
- [ ] 执行过程规范有序
- [ ] 协作执行高效协调
- [ ] 结果报告完整清晰
- [ ] 经验学习持续进行

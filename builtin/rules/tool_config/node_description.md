# 节点描述生成规则

## 规则简介

此规则用于将用户提供之节点描述信息写入`~/.jarvis/gateway/node_description.md`文件。该文件会被系统信息模块自动读取，并在Child-Master心跳中上报至Master节点，供`gateway_manager`工具之`list_nodes`操作返回。

## 汝必守之原则

### 1. 描述内容来源

- **必**：描述内容由用户提供，不得自行编造
- **必**：用户可提供任意格式之描述文本，规则负责写入文件
- **禁**：在用户未提供内容时生成默认描述

### 2. 文件路径

- **必**：写入路径为`~/.jarvis/gateway/node_description.md`
- **必**：若目录不存在，先创建目录再写入文件
- **禁**：写入其他路径

### 3. 大小限制

- **必**：描述文件大小不得超过10KB（10240字节）
- **必**：若用户提供之描述超过10KB，截断内容并告知用户
- **建议**：描述内容控制在1-2KB以内，保持简洁实用

### 4. 文件格式

- **必**：用Markdown格式
- **必**：用UTF-8编码
- **建议**：包含节点名称、用途、硬件配置、负责人等关键信息

## 汝必执行之操作

### 操作1：收集描述内容

1. 询问用户提供节点描述内容
2. 确认用户提供之描述内容完整

### 操作2：写入描述文件

1. 检查目录`~/.jarvis/gateway/`是否存在，不存在则创建
2. 检查描述内容大小，超过10KB则截断并告知用户
3. 将描述内容写入`~/.jarvis/gateway/node_description.md`
4. 确认写入成功

### 操作3：验证

1. 读取写入之文件内容，确认与预期一致
2. 告知用户描述将在下次心跳时自动上报至Master节点

## 描述内容建议模板

```markdown
# 节点名称

## 基本信息

- **节点ID**: xxx
- **用途**: xxx
- **负责人**: xxx

## 硬件配置

- **CPU**: xxx
- **内存**: xxx GB
- **磁盘**: xxx GB

## 备注

xxx
```

## 检查清单

完成任务后，汝必确认：

- [ ] 描述文件已写入`~/.jarvis/gateway/node_description.md`
- [ ] 文件大小未超过10KB
- [ ] 文件编码为UTF-8
- [ ] 文件内容与用户提供之描述一致
- [ ] 已告知用户描述将在心跳中自动上报

# 远程部署规范

## 连接管理

### SSH 连接

- 使用 SSH 密钥认证，避免密码登录
- 配置 SSH 配置文件（`~/.ssh/config`）简化连接
- 必要时用 SSH 隧道转发端口

### 安全连接

- 禁止 root 直接登录
- 使用非标准端口降低被扫描风险
- 配置防火墙，只放行可信 IP
- 启用 Fail2Ban 防止暴力破解

## 环境配置

### 系统准备

- 更新系统软件包
- 安装必要工具（git、curl、wget 等）
- 配置时区与语言环境
- 创建专用的部署用户

### 依赖安装

- 安装 Python 环境（pyenv 或 conda）
- 安装 Node.js 环境（nvm）
- 安装 Docker 与 Docker Compose
- 安装数据库（PostgreSQL、MySQL、Redis 等）

## 部署流程

### 1. 代码传输

- 用 `git clone` 或 `rsync` 传输代码
- 配置 git hooks 实现自动部署
- 用 CI/CD 流水线自动化部署

### 2. 环境变量

- 建立 `.env` 文件配置环境变量
- 用密钥管理服务存放敏感信息
- 区分开发、测试、生产环境配置

### 3. 服务管理

- 用 systemd 管理服务
- 配置日志轮转
- 设置监控与告警

### 4. 反向代理

- 配置 Nginx 或 Caddy 作为反向代理
- 配置 SSL 证书（如 Let's Encrypt）
- 设置负载均衡

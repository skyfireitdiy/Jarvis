# 整洁代码的规

## 必须守的核心原则

### 一、可读性为先（至要）

**行规：**

- **必须**：代码为人而作，机器偶为执行
- **必须**：用有义的变量名与函数名
- **必须**：代码当自释，减不必要的注
- **禁止**：用无义的变量名（如 `a`, `b`, `x`, `temp`）

**命名的要：**

- 变量名必明其用
- 函数名必明其功
- 类名必明其责

### 二、单一职责（必须遵守）

**函数的要：**

- **必须**：每函数只为一事
- **必须**：函数名当准述其功
- **禁止**：一函数行多不相关的事

**类的要：**

- **必须**：每类唯有一变的由
- **必须**：类的职责当清晰明确
- **禁止**：造职责混乱的"上帝类"

**代码的要：**

- **必须**：保函数与类的简洁
- **必须**：若函数或类趋复杂，必拆分

### 三、DRY 的则（禁重复）

**行规：**

- **禁止**：写重复的代码
- **必须**：提公共逻辑入函数或类中
- **必须**：用配置而非硬编码
- **必须**：识而除重复的模式

## 命名规范（必须遵守）

### 变量与函数命名

- **必须**：用描述的名，避缩写
- **必须**：函数名当为动词或动词短语（如 `calculateTotal`, `getUserById`）
- **必须**：类名当为名词或名词短语（如 `UserService`, `OrderProcessor`）
- **必须**：布尔变量当用 is/has/can 等前缀（如 `isValid`, `hasPermission`, `canEdit`）
- **禁止**：用单字母变量名（循环计数器除外）
- **禁止**：用误导的名

### 常量命名

- **必须**：常量当用全大写，词间以下划线隔（如 `MAX_RETRY_COUNT`, `DEFAULT_TIMEOUT`）
- **必须**：魔法数字与字符串必定义为常量

## 函数设计规范（必须遵守）

### 函数长度

- **必须**：函数当短小，最好不过二十行
- **必须**：若函数过二十行，当虑拆分
- **必须**：函数当只为一事，善为一事

### 函数参数

- **必须**：函数参数当尽可能少，最好不过三个
- **必须**：若参数过三个，当虑用对象或配置类
- **禁止**：用布尔参数控函数行为（用策略模式或函数重载）

### 函数行为

- **必须**：避副作用，函数当可预测
- **必须**：函数当返一致的结果类型
- **禁止**：函数既改状态又返值（除非明确需的）

## 代码组织规范（必须遵守）

### 代码布局

- **必须**：相关代码当放一处
- **必须**：用空行分逻辑块
- **必须**：保一致的代码风格
- **必须**：循项目的代码格式化规范

### 代码清理

- **必须**：删未用的代码
- **必须**：删过时的注
- **必须**：删调试代码（如 `console.log`, `print` 语句）
- **禁止**：提交含调试代码的代码

## 代码示例

### ❌ 不善的实践

```python
def calc(x, y, z):
    return x * y + z * 2

def process(data):
    # 处理数据
    result = []
    for i in data:
        if i > 0:
            result.append(i * 2)
    return result
```

### ✅ 善的实践

```python
TAX_MULTIPLIER = 2.0

def calculate_total_price(quantity: int, unit_price: float, tax_rate: float) -> float:
    subtotal = quantity * unit_price
    tax = subtotal * tax_rate
    return subtotal + tax

def filter_and_double_positive_numbers(numbers: list[int]) -> list[int]:
    """过滤正数并翻倍"""
    return [number * 2 for number in numbers if number > 0]
```

## 代码质量检查清单

提交代码前，请务必确认：

- [ ] 所有变量与函数皆有义的名
- [ ] 函数长度不过二十行（或合理的度）
- [ ] 函数参数不过三个
- [ ] 无重复代码
- [ ] 无未用的代码与注
- [ ] 代码格式合项目规范
- [ ] 代码自释，不需过多的注
- [ ] 每函数只为一事
- [ ] 每类职责单一

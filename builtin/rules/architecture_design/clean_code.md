# 整洁代码之规

## 汝必守之核心原则

### 一、可读性为先（至要）

**行规：**

- **必**：代码为人而作，机器偶为执行
- **必**：用有义之变量名与函数名
- **必**：代码当自释，减不必要之注
- **禁**：用无义之变量名（如 `a`, `b`, `x`, `temp`）

**命名之要：**

- 变量名必明其用
- 函数名必明其功
- 类名必明其责

### 二、单一职责（必遵）

**函数之要：**

- **必**：每函数只为一事
- **必**：函数名当准述其功
- **禁**：一函数行多不相关之事

**类之要：**

- **必**：每类唯有一变之由
- **必**：类之职责当清晰明确
- **禁**：造职责混乱之"上帝类"

**代码之要：**

- **必**：保函数与类之简洁
- **必**：若函数或类趋复杂，必拆分

### 三、DRY 之则（禁重复）

**行规：**

- **禁**：写重复之代码
- **必**：提公共逻辑入函数或类中
- **必**：用配置而非硬编码
- **必**：识而除重复之模式

## 命名规范（必遵）

### 变量与函数命名

- **必**：用描述之名，避缩写
- **必**：函数名当为动词或动词短语（如 `calculateTotal`, `getUserById`）
- **必**：类名当为名词或名词短语（如 `UserService`, `OrderProcessor`）
- **必**：布尔变量当用 is/has/can 等前缀（如 `isValid`, `hasPermission`, `canEdit`）
- **禁**：用单字母变量名（循环计数器除外）
- **禁**：用误导之名

### 常量命名

- **必**：常量当用全大写，词间以下划线隔（如 `MAX_RETRY_COUNT`, `DEFAULT_TIMEOUT`）
- **必**：魔法数字与字符串必定义为常量

## 函数设计规范（必遵）

### 函数长度

- **必**：函数当短小，最好不过二十行
- **必**：若函数过二十行，当虑拆分
- **必**：函数当只为一事，善为一事

### 函数参数

- **必**：函数参数当尽可能少，最好不过三个
- **必**：若参数过三个，当虑用对象或配置类
- **禁**：用布尔参数控函数行为（用策略模式或函数重载）

### 函数行为

- **必**：避副作用，函数当可预测
- **必**：函数当返一致之结果类型
- **禁**：函数既改状态又返值（除非明确需之）

## 代码组织规范（必遵）

### 代码布局

- **必**：相关代码当放一处
- **必**：用空行分逻辑块
- **必**：保一致之代码风格
- **必**：循项目之代码格式化规范

### 代码清理

- **必**：删未用之代码
- **必**：删过时之注
- **必**：删调试代码（如 `console.log`, `print` 语句）
- **禁**：提交含调试代码之代码

## 代码示例

### ❌ 不善之实践

```python
def calc(x, y, z):
    return x * y + z * 2

def process(data):
    # 处理数据
    result = []
    for i in data:
        if i > 0:
            result.append(i * 2)
    return result
```

### ✅ 善之实践

```python
TAX_MULTIPLIER = 2.0

def calculate_total_price(quantity: int, unit_price: float, tax_rate: float) -> float:
    subtotal = quantity * unit_price
    tax = subtotal * tax_rate
    return subtotal + tax

def filter_and_double_positive_numbers(numbers: list[int]) -> list[int]:
    """过滤正数并翻倍"""
    return [number * 2 for number in numbers if number > 0]
```

## 代码质量检查清单

提交代码前，汝必确认：

- [ ] 所有变量与函数皆有义之名
- [ ] 函数长度不过二十行（或合理之度）
- [ ] 函数参数不过三个
- [ ] 无重复代码
- [ ] 无未用之代码与注
- [ ] 代码格式合项目规范
- [ ] 代码自释，不需过多之注
- [ ] 每函数只为一事
- [ ] 每类职责单一

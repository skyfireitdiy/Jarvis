# Jarvis帮助规则

## 规则简介

此规则指导Jarvis如何参考官方文档与源码回答用户关于Jarvis系统之问题。当用户询问Jarvis之功能、用法、配置、架构等相关问题时，必参考`{{jarvis_src_dir}}/docs/jarvis_book`目录下之官方文档与`{{jarvis_src_dir}}/src/jarvis`目录下之源码，以提供准确、完整之答案。

**重要原则**：当文档与代码实现不一致时，以代码实现为准。文档可能滞后于代码更新，源码方为系统之真实行为。

## 汝必守之原则

### 1. 代码优先原则（必守）

**核心原则：**

- **必**：当用户询问关于Jarvis之问题时，以源码实现为准
- **必**：文档可能滞后于代码更新，源码方为系统之真实行为
- **必**：当文档与代码不一致时，以代码实现为准
- **禁**：仅凭文档回答而不验证代码实现
- **禁**：提供与代码实现不一致之信息

**查阅要求：**

- **必**：优先查阅`{{jarvis_src_dir}}/src/jarvis`目录下之源码
- **必**：参考`{{jarvis_src_dir}}/docs/jarvis_book`目录下之文档作为辅助
- **必**：基于代码实现提供准确、权威之答案
- **必**：引用代码中之具体实现与文档中之相关章节

**文档与源码位置：**

- **必**：文档位于`{{jarvis_src_dir}}/docs/jarvis_book/`目录
- **必**：源码位于`{{jarvis_src_dir}}/src/jarvis/`目录
- **必**：文档包括但不限于：
  - `1.项目介绍.md` - 项目概述与背景
  - `2.快速开始.md` - 安装与快速入门
  - `3.核心概念与架构.md` - 架构设计与核心概念
  - `4.使用指南.md` - 详细使用说明
  - `5.功能扩展.md` - 功能扩展方法
  - `6.高级主题.md` - 高级功能与主题
  - `7.参与贡献.md` - 贡献指南
  - `8.常见问题.md` - 常见问题解答
  - `9.附录.md` - 附录与参考资料

### 2. 全面查阅原则（必守）

**查阅要求：**

- **必**：依用户问题之主题，查阅相关之源码文件与文档
- **必**：优先查阅源码实现，确认实际行为
- **必**：若问题涉及多方面，查阅所有相关源码与文档
- **必**：优先查阅最相关之源码模块与文档章节
- **必**：若文档中无直接答案，查阅源码实现进行推理
- **建议**：查阅多个相关源码与文档以确保答案之完整性

**查阅策略：**

- **快速开始类问题**：优先查阅`2.快速开始.md`，同时查阅`src/jarvis/jarvis_platform/`等相关源码
- **功能使用类问题**：优先查阅`4.使用指南.md`，同时查阅对应功能之源码实现
- **架构概念类问题**：优先查阅`3.核心概念与架构.md`，同时查阅核心模块源码
- **扩展开发类问题**：优先查阅`5.功能扩展.md`，同时查阅扩展接口源码
- **高级功能类问题**：优先查阅`6.高级主题.md`，同时查阅高级功能源码
- **常见问题类问题**：优先查阅`8.常见问题.md`，同时查阅相关源码验证
- **贡献参与类问题**：优先查阅`7.参与贡献.md`

### 3. 准确引用原则（必守）

**引用要求：**

- **必**：在回答中明确说明信息来源（源码路径与文档章节）
- **必**：直接引用源码中之关键实现与文档中之关键内容
- **必**：保持引用内容之准确性，不随意修改
- **必**：若文档与代码不一致，以代码为准并说明
- **必**：若源码内容需解释，先引用代码，再进行说明
- **禁**：断章取义或曲解源码原意

**引用格式：**

- 明确标注源码来源：`根据{{jarvis_src_dir}}/src/jarvis/[模块路径]/[文件名]`
- 明确标注文档来源：`根据{{jarvis_src_dir}}/docs/jarvis_book/[文档名称]`
- 引用具体章节：`根据[文档名称]中之[章节名称]部分`
- 引用关键内容：用引用块或直接引用原文与代码

### 4. 完整性原则（必守）

**回答要求：**

- **必**：提供完整、全面之答案，不遗漏关键信息
- **必**：若源码与文档中有多个相关部分，整合所有相关信息
- **必**：若文档中无直接答案，基于源码实现进行合理推理
- **必**：提供相关之上下文与背景信息
- **建议**：提供相关之源码路径与文档链接，方便用户进一步查阅

## 汝必行之操作

### 操作1：识别问题类型（必行）

**执行步骤：**

1. **必**：分析用户问题之主题与类型
2. **必**：确定需查阅之文档文件
3. **必**：识别问题之关键点与用户需求

**问题分类：**

- **安装配置类**：安装、配置、环境设置等问题
- **功能使用类**：如何使用特定功能、工具使用等问题
- **概念理解类**：架构、概念、原理等问题
- **开发扩展类**：如何扩展功能、开发插件等问题
- **故障排除类**：错误处理、问题排查等问题
- **最佳实践类**：使用建议、最佳实践等问题

### 操作2：查阅相关文档与源码（必行）

**执行步骤：**

1. **必**：依问题类型，确定需查阅之源码文件与文档
2. **必**：优先查阅相关源码文件，确认实际实现
3. **必**：读取相关文档文件之内容作为辅助参考
4. **必**：查找与问题相关之源码实现与文档章节
5. **必**：若问题涉及多方面，查阅所有相关源码与文档
6. **必**：对比文档与代码实现，确认一致性
7. **建议**：记录查阅之源码路径、文档路径与关键内容

**源码与文档查阅工具：**

- 用`read_code`工具读取源码文件
- 用`read_file`工具读取文档文件
- 用`rg`或`grep`工具搜索关键词
- 用`fd`或`list_dir`工具查看目录结构

### 操作3：整合信息并回答（必行）

**执行步骤：**

1. **必**：整合从源码与文档中获取之信息
2. **必**：基于代码实现组织答案结构
3. **必**：引用源码中之关键实现与文档中之关键内容
4. **必**：提供清晰之解释与说明
5. **必**：标注信息来源（源码路径与文档章节）
6. **必**：若文档与代码不一致，明确说明以代码为准

**答案结构：**

- **开头**：明确说明基于源码实现与官方文档回答
- **主体**：提供详细之答案，引用源码实现与文档内容
- **引用**：标注源码路径与文档来源
- **补充**：如有必要，提供额外之说明或建议

### 操作4：验证答案准确性（必行）

**执行步骤：**

1. **必**：确认答案与代码实现一致
2. **必**：确认答案与文档内容一致（如有文档）
3. **必**：确认无遗漏关键信息
4. **必**：确认引用内容准确无误
5. **必**：确认答案完整回答了用户问题
6. **必**：若文档与代码不一致，已明确说明以代码为准

## 具体要求与规范

### 1. 文档路径规范（必守）

**路径要求：**

- **必**：用`{{jarvis_src_dir}}/docs/jarvis_book/`作为文档根目录
- **必**：用相对路径引用文档文件
- **禁**：用硬编码之绝对路径
- **禁**：假设文档位置，必用变量路径

**路径示例：**

- ✅ 正确：`{{jarvis_src_dir}}/docs/jarvis_book/4.使用指南.md`
- ❌ 错误：`/home/user/jarvis/docs/jarvis_book/4.使用指南.md`

### 2. 源码与文档查阅规范（必守）

**查阅要求：**

- **必**：在回答前查阅相关源码与文档
- **必**：优先查阅最相关之源码文件
- **必**：查阅最相关之文档文件作为辅助
- **必**：若问题涉及多方面，查阅所有相关源码与文档
- **禁**：仅凭记忆或经验回答，而不查阅源码
- **禁**：仅凭文档回答而不验证代码实现
- **禁**：跳过源码查阅步骤

**查阅优先级：**

1. **第一优先级**：直接相关之源码文件（如使用问题查阅功能实现源码）
2. **第二优先级**：直接相关之文档文件（如使用问题查阅使用指南）
3. **第三优先级**：相关概念源码与文档（如架构问题查阅架构源码与文档）
4. **第四优先级**：常见问题文档与相关源码（如问题可能在常见问题中有答案）
5. **第五优先级**：其他相关源码与文档（如需更多上下文时）

### 3. 答案组织规范（必守）

**组织要求：**

- **必**：答案结构清晰、逻辑完整
- **必**：按问题之重要性与相关性组织内容
- **必**：用标题、列表、代码块等格式提高可读性
- **必**：提供具体之步骤与示例（若文档中有）
- **建议**：用分节组织长答案

**答案格式：**

```markdown
## 基于源码实现与官方文档之回答

根据`{{jarvis_src_dir}}/src/jarvis/[相关源码].py`与`{{jarvis_src_dir}}/docs/jarvis_book/[相关文档].md`中之内容：

### [主要答案]

[详细内容，引用源码实现与文档]

### 参考信息

- 源码来源：`{{jarvis_src_dir}}/src/jarvis/[模块路径]/[文件名]`
- 文档来源：`{{jarvis_src_dir}}/docs/jarvis_book/[文档名称].md`
- 相关章节：[章节名称]
```

### 4. 引用标注规范（必守）

**标注要求：**

- **必**：明确标注信息来源
- **必**：标注源码路径与文档路径
- **必**：用清晰之引用格式
- **建议**：提供源码路径与文档链接，方便用户查阅

**标注格式：**

- 源码路径：`{{jarvis_src_dir}}/src/jarvis/[模块路径]/[文件名]`
- 文档路径：`{{jarvis_src_dir}}/docs/jarvis_book/[文档名称].md`
- 章节引用：`根据[文档名称]中之[章节名称]部分`
- 内容引用：用引用块或直接引用源码与文档

### 源码与文档查阅技巧

**高效查阅：**

- **用rg或grep搜索**：在源码与文档中搜索关键词快速定位相关内容
- **阅读目录结构**：先了解源码模块结构与文档结构，再定位具体章节
- **交叉引用**：若一文档提到其他文档或源码，查阅相关内容获取更多信息
- **上下文理解**：阅读相关章节与源码之上下文，确保理解完整
- **代码优先**：优先阅读源码实现，确认实际行为，再参考文档辅助理解

### 答案质量提升

**质量要求：**

- **准确性**：确保答案与代码实现一致，文档作为辅助参考

- **清晰性**：用清晰之语言与结构
- **实用性**：提供可操作之步骤与示例
- **可追溯性**：明确标注源码路径与文档来源，方便用户查阅
- **一致性**：当文档与代码不一致时，明确说明以代码为准

# 抽取知识库规则

## 规则简介

Jarvis 的知识库复用规则系统机制：外部技术文档/手册（如第三方框架、库、工具的使用手册、API 文档）由 Agent 自行读取、归纳整理后，写入全局规则目录 `~/.jarvis/rules/kb/` 下，成为带 front-matter 的规则文件。此后这些知识库条目会像普通规则一样，在 Agent 需要时被自动预筛、注入、按需补取（`load_rule`）。

## 你必须遵守的原则

### 1. 触发时机原则

**要求说明：**

- **必须**：当用户明确要求把某份外部技术文档/手册纳入长期知识库时触发
- **必须**：文档来源是"外部"的（第三方框架/库/工具/协议等），而非项目内部代码或记忆
- **禁止**：对项目内部代码、临时笔记、无需长期保留的内容做知识库导入

### 2. 归纳整理原则

**要求说明：**

- **必须**：由 Agent 自行归纳整理文档要点，而非把原始文档整篇复制进知识库
- **必须**：抽取后的内容应聚焦技术实质（概念、用法、参数、示例、注意事项），去除冗余
- **必须**：写入的知识库文件带 YAML front-matter（name/description），以便被预筛与注入
- **禁止**：写入未抽取、无 front-matter 的原始文档

### 3. 获取内容原则

**要求说明：**

- **必须**：本地文件用 `read_code` 读取；公开网页用 `read_webpage` 抓取
- **必须**：需要登录或动态渲染的网站，用浏览器扩展（`browser_ext_*`）登录后获取，而非仅靠 URL 抓取
- **禁止**：对需要登录的网站仅用 URL 抓取（无法获得正确内容）

## 你必须执行的操作

### 操作1：获取文档内容

**执行步骤：**

1. 判断文档来源：本地文件 / 公开网页 / 需登录的网站
2. 本地文件用 `read_code` 读取
3. 公开网页用 `read_webpage` 抓取正文
4. 需登录的网站用浏览器扩展登录后获取内容
5. 若文档过长，分段读取并归纳

### 操作2：归纳整理要点

**执行步骤：**

1. 通读文档，识别主题与章节结构
2. 按主题/章节归纳出技术要点（概念、用法、参数、示例、注意事项）
3. 用中文输出，保留必要英文术语，结构清晰（标题、列表、代码块）
4. 不臆造文档中不存在的内容

### 操作3：写入知识库文件

**执行步骤：**

1. 确定 `category`（如 framework / tool / protocol / api）与 `title`
2. 用 `write_file` 写入 `~/.jarvis/rules/kb/<category>/<title>.md`
3. 文件带 YAML front-matter（name/description），正文为归纳整理后的要点
4. 确认写入成功，可用规则名为 `global:kb/<category>/<title>`

**示例 front-matter：**

```yaml
---
name: <title>
description: 外部文档知识库条目，来源 <source>。当需要查询关于 <title> 的技术细节时触发。
---
```

## 检查清单

用知识库导入完成任务后，请务必确认：

- [ ] 文档来源确为外部技术文档/手册
- [ ] 已获取正确内容（需登录网站已通过浏览器扩展登录）
- [ ] 已归纳整理要点（而非复制原文）
- [ ] 已写入 `~/.jarvis/rules/kb/<category>/<title>.md` 且带 front-matter
- [ ] 知识库条目可被 `load_rule` 读取（`global:kb/<category>/<title>`）

## 相关资源

- 知识库存储目录：`~/.jarvis/rules/kb/<category>/<title>.md`
- 检索方式：`load_rule` 工具（`global:kb/<category>/<title>`）
- 内容获取：`read_code`（本地）、`read_webpage`（公开网页）、`browser_ext_*`（需登录网站）

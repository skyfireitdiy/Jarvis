# 文档编写规则

## 汝必遵守之文档原则

### 1. 清晰性原则（必遵）

**文档要求：**

- **必**：文档应清晰准确
- **必**：用简单之语言
- **必**：避不必要之技术术语
- **必**：必要时提供术语解释

**写作要求：**

- 用短句，避长句
- 用主动语态
- 用具体之例子
- 避模糊之表达

### 2. 完整性原则（必遵）

**文档要求：**

- **必**：文档应覆盖所有重要功能
- **必**：包含使用示例
- **必**：说明限制与注意事项
- **必**：说明前提条件与依赖

**内容要求：**

- 功能描述：说明功能所做之事
- 使用方法：说明如何使用
- 参数说明：说明所有参数
- 返回值说明：说明返回值
- 异常说明：说明可能抛出之异常
- 示例代码：提供可运行之示例

### 3. 及时性原则（必遵）

**维护要求：**

- **必**：代码变更时同步更新文档
- **必**：文档应反映当前实现
- **必**：删除过时之文档
- **禁**：文档与代码不一致

**更新时机：**

- 添加新功能时，立即更新文档
- 修改功能时，同步更新文档
- 删除功能时，删除相关文档
- 定期检查文档与代码之一致性

## 汝必编写之文档类型

### 1. 代码注释（必编）

**注释要求：**

- **必**：解释"为何"，而非"做何"
- **必**：复杂逻辑必有注释
- **必**：公共 API 必有文档字符串
- **禁**：注释重复代码内容

**注释内容：**

- 业务逻辑说明
- 算法选择原因
- 特殊处理之原因
- 已知问题与限制

**文档字符串格式：**

```python
def calculate_total(items: list[Item], discount: float = 0.0) -> float:
    """计算商品总价

    参数:
        items: 商品列表，不能为空
        discount: 折扣率，范围 0.0-1.0，默认 0.0

    返回:
        计算后的总价，已应用折扣

    异常:
        ValueError: 当 items 为空或 discount 不在有效范围时抛出

    示例:
        >>> items = [Item(price=10.0), Item(price=20.0)]
        >>> calculate_total(items, discount=0.1)
        27.0
    """
    pass
```

### 2. README 文档（必编）

**README 要求：**

- **必**：项目概述与快速开始
- **必**：安装与配置说明
- **必**：使用示例
- **必**：常见问题解答（如适用）

**README 结构：**

- 项目简介
- 功能特性
- 安装步骤
- 配置说明
- 快速开始
- 使用示例
- API 文档链接
- 贡献指南
- 许可证信息

### 3. API 文档（必编）

**API 文档要求：**

- **必**：函数签名与参数说明
- **必**：返回值说明
- **必**：使用示例
- **必**：异常说明

**文档内容：**

- 函数/方法签名
- 参数类型与说明
- 返回值类型与说明
- 可能抛出之异常
- 使用示例
- 相关 API 链接

- [ ] 复杂逻辑有注释说明
- [ ] 注释解释"为何"而非"做何"
- [ ] 无过时之注释

**README：**

- [ ] README 包含快速开始指南

# 暗色主题设计规范

## 色彩系统

### 背景色

- **主背景**：深灰色（`#1a1a2e` 或相近）
- **次级背景**：比主背景略浅（`#16213e`）
- **卡片背景**：再浅一层（`#0f3460`）
- **输入框背景**：深色（`#0d1b2a`）

### 文字色

- **主文字**：高对比白（`#e0e0e0`）
- **次级文字**：中等对比灰（`#a0a0a0`）
- **禁用文字**：低对比深灰（`#606060`）
- **链接文字**：亮蓝（`#64b5f6`）

### 强调色

- **主色**：保留品牌色，但适当降低饱和度
- **成功**：柔和绿（`#4caf50`）
- **警告**：柔和橙（`#ff9800`）
- **错误**：柔和红（`#f44336`）
- **信息**：柔和蓝（`#2196f3`）

## 设计原则

- **减少眩光**：避免纯黑背景，改用深灰色
- **保证对比度**：文字与背景对比度 ≥ 4.5:1
- **柔和阴影**：使用半透明阴影，而非纯黑阴影
- **护眼**：降低蓝光比例，减轻用眼疲劳

## 组件适配

### 导航栏

- 背景：主背景色
- 悬停：使用半透明高亮
- 选中：使用强调色

### 按钮

- 默认：以主色填充
- 悬停：亮度略微提升
- 禁用：降低透明度

### 表单

- 输入框：深色底、浅色描边
- 聚焦：描边变为强调色
- 错误：描边变为红色

### 模态框

- 遮罩：半透明黑（`rgba(0,0,0,0.5)`）
- 内容区：次级背景色

## 检查清单

- [ ] 背景使用深灰色而非纯黑
- [ ] 文字对比度达标
- [ ] 强调色已降低饱和度
- [ ] 阴影为半透明
- [ ] 组件已适配暗色
- [ ] 过渡动画平滑

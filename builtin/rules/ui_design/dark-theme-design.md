# 暗色主题设计规范

## 色彩系统

### 背景色

- **主背景**：用深灰色（#1a1a2e或类似色）
- **次背景**：略浅于主背景（#16213e）
- **卡片背景**：再浅一层（#0f3460）
- **输入框背景**：深色（#0d1b2a）

### 文字色

- **主文字**：高对比白（#e0e0e0）
- **次文字**：中对比灰（#a0a0a0）
- **禁用文字**：低对比深灰（#606060）
- **链接文字**：亮蓝（#64b5f6）

### 强调色

- **主色**：保品牌色但降饱和度
- **成功**：柔绿（#4caf50）
- **警告**：柔橙（#ff9800）
- **错误**：柔红（#f44336）
- **信息**：柔蓝（#2196f3）

## 设计原则

- **减眩光**：避纯黑色背景，用深灰色
- **保对比度**：确文字与背景对比度≥4.5:1
- **柔阴影**：用半透明阴影而非纯黑阴影
- **减蓝光**：降蓝色光比例，护视力

## 组件适配

### 导航栏

- 背景：主背景
- 悬停效果：用半透明高亮
- 激活状态：用强调色

### 按钮

- 默认：填充为主色
- 悬停：亮度略升
- 禁用：降透明度

### 表单

- 输入框：深底浅框
- 聚焦：框变强调色
- 错误：框变红色

### 模态框

- 遮罩：半透明黑（rgba(0,0,0,0.5)）
- 内容区：次背景

## 检查清单

- [ ] 背景色用深灰色而非纯黑
- [ ] 文字对比达标
- [ ] 强调色已降饱和度
- [ ] 阴影用半透明色
- [ ] 组件已适暗色
- [ ] 过渡动画平滑

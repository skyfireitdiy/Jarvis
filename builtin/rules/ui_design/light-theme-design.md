# 亮色主题设计规范

## 色彩系统

### 背景色

- **主背景**：纯白或近白色（`#ffffff` 或 `#fafafa`）
- **次级背景**：浅灰（`#f5f5f5`）
- **卡片背景**：纯白（`#ffffff`）
- **输入框背景**：浅灰（`#f0f0f0`）

### 文字色

- **主文字**：高对比黑（`#1a1a1a`）
- **次级文字**：中等对比灰（`#666666`）
- **禁用文字**：低对比浅灰（`#b0b0b0`）
- **链接文字**：蓝色（`#1976d2`）

### 强调色

- **主色**：保留品牌色
- **成功**：绿色（`#4caf50`）
- **警告**：橙色（`#ff9800`）
- **错误**：红色（`#f44336`）
- **信息**：蓝色（`#2196f3`）

## 设计原则

- **简洁清晰**：保持界面干净，避免视觉杂乱
- **充足留白**：使用足够的边距与间距
- **柔和阴影**：使用浅色半透明阴影，不喧宾夺主
- **高可读性**：确保文字与背景的对比度 ≥ 4.5:1

## 组件适配

### 导航栏

- 背景：主背景色
- 底部分隔线：浅色分隔
- 选中状态：使用强调色

### 按钮

- 默认：以主色填充
- 悬停：亮度略微降低
- 禁用：降低透明度

### 表单

- 输入框：浅色底、深色描边
- 聚焦：描边变为强调色
- 错误：描边变为红色

### 模态框

- 遮罩：半透明黑（`rgba(0,0,0,0.3)`）
- 内容区：纯白背景

## 检查清单

- [ ] 背景色使用白色或近白色
- [ ] 文字对比度达标
- [ ] 阴影柔和且半透明
- [ ] 组件已适配亮色
- [ ] 界面简洁清晰
- [ ] 过渡动画平滑

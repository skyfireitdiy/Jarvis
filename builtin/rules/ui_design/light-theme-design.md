# 亮色主题设计规范

## 色彩系统

### 背景色

- **主背景**：用纯白或近白色（#ffffff或#fafafa）
- **次背景**：浅灰色（#f5f5f5）
- **卡片背景**：纯白（#ffffff）
- **输入框背景**：浅灰（#f0f0f0）

### 文字色

- **主文字**：高对比黑（#1a1a1a）
- **次文字**：中对比灰（#666666）
- **禁用文字**：低对比浅灰（#b0b0b0）
- **链接文字**：蓝色（#1976d2）

### 强调色

- **主色**：保品牌色
- **成功**：绿色（#4caf50）
- **警告**：橙色（#ff9800）
- **错误**：红色（#f44336）
- **信息**：蓝色（#2196f3）

## 设计原则

- **简洁清晰**：保界面干净，避视觉杂乱
- **充足留白**：用足够之内边距与间距
- **柔阴影**：用浅色半透明阴影
- **高可读性**：确文字与背景对比度≥4.5:1

## 组件适配

### 导航栏

- 背景：主背景
- 边框：底浅分隔线
- 激活状态：用强调色

### 按钮

- 默认：填充为主色
- 悬停：亮度略降
- 禁用：降透明度

### 表单

- 输入框：浅底深框
- 聚焦：框变强调色
- 错误：框变红色

### 模态框

- 遮罩：半透明黑（rgba(0,0,0,0.3)）
- 内容区：纯白底

## 检查清单

- [ ] 背景色用白色或近白色
- [ ] 文字对比达标
- [ ] 阴影用柔和半透明色
- [ ] 组件已适亮色
- [ ] 界面简洁清晰
- [ ] 过渡动画平滑

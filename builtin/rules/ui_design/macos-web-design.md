# macOS 风格 Web 设计规范

## 设计语言

### 核心原则

- **简洁优雅**：遵循 Apple 设计哲学，追求极致的简洁
- **材质质感**：善用毛玻璃、半透明等材质效果
- **流畅动画**：使用平滑过渡与弹性动画
- **空间层次**：用阴影与模糊营造深度感

### 色彩系统

- **系统色**：使用 Apple 系统色（系统蓝、系统红等）
- **背景色**：亮色用浅灰（`#f5f5f7`），暗色用深灰（`#1c1c1e`）
- **强调色**：使用 Apple 蓝（`#007aff`）

## 组件规范

### 窗口

- 圆角：大圆角（12–16px）
- 标题栏：含红黄绿三个窗口控制按钮
- 阴影：柔和扩散阴影
- 工具栏：半透明毛玻璃

### 按钮

- **系统按钮**：文字按钮，无边框
- **推送按钮**：蓝色填充、白色文字
- **圆形按钮**：用于图标操作

### 表单

- 输入框：圆角矩形，聚焦时出现蓝框
- 选择器：原生风格下拉菜单
- 滑块：系统风格滑块
- 开关：iOS 风格开关

### 导航

- **侧边栏**：半透明毛玻璃效果
- **标签栏**：图标加文字
- **面包屑**：系统字体、箭头分隔

## 字体规范

- **系统字体**：SF Pro 或 Inter
- **大标题**：Large Title（34px）
- **次标题**：Title 2（22px）
- **正文**：Body（17px）
- **脚注**：Footnote（13px）

## 动画规范

- **持续时间**：0.2–0.4s
- **缓动函数**：`cubic-bezier(0.25, 0.1, 0.25, 1)`
- **弹性动画**：使用 spring 动画
- **过渡**：透明度与位移组合

## 检查清单

- [ ] 使用 Apple 系统色
- [ ] 窗口有红黄绿控制按钮
- [ ] 使用毛玻璃效果
- [ ] 动画流畅自然
- [ ] 使用系统字体
- [ ] 圆角数值一致
- [ ] 阴影柔和

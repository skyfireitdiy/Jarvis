# macOS风格Web设计规范

## 设计语言

### 核心原则

- **简洁优雅**：循Apple设计哲学，求极致简洁
- **材质质感**：用毛玻璃、半透明等材质效果
- **流畅动画**：用平滑过渡与弹性动画
- **空间层次**：通阴影与模糊建深度感

### 色彩系统

- **系统色**：用Apple系统色（系统蓝、系统红等）
- **背景色**：亮色用浅灰（#f5f5f7），暗色用深灰（#1c1c1e）
- **强调色**：用Apple蓝色（#007aff）

## 组件规范

### 窗口

- 圆角：大圆角（12px-16px）
- 标题栏：含红黄绿三色控制按钮
- 阴影：柔扩散影
- 工具栏：半透明毛玻璃

### 按钮

- **系统按钮**：文字按钮，无边框
- **推送按钮**：蓝色填充，白色文字
- **圆形按钮**：用于图标操作

### 表单

- 输入框：圆角矩形，聚焦时蓝框
- 选择器：原生风下拉菜单
- 滑块：系统风滑块
- 开关：iOS风开关

### 导航

- **侧边栏**：半透明毛玻璃效果
- **标签栏**：图标加文字
- **面包屑**：系统字体，箭头分隔

## 字体规范

- **系统字体**：用SF Pro或Inter
- **标题**：大标题用Large Title（34px）
- **次标题**：Title 2（22px）
- **正文**：Body（17px）
- **脚注**：Footnote（13px）

## 动画规范

- **持续时间**：0.2s-0.4s
- **缓动函数**：用cubic-bezier(0.25, 0.1, 0.25, 1)
- **弹性动画**：用spring动画
- **过渡**：透明度与位移组合

## 检查清单

- [ ] 用Apple系统色
- [ ] 窗口有红黄绿控制钮
- [ ] 用毛玻璃效果
- [ ] 动画流畅自然
- [ ] 字体用系统字体
- [ ] 圆角值一致
- [ ] 阴影柔和

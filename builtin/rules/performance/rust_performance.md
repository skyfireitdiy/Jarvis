# Rust性能优化规范

## 基本原则

- **零成本抽象**：用Rust之零成本抽象特性，不引入运行时开销
- **所有权与借用**：善用所有权系统，避不必要之克隆
- **静态分发**：优先用泛型静态分发，而非trait对象动态分发
- **内存布局**：优化数据结构之内存布局，减缓存未命中

## 性能分析工具

- **perf**：Linux性能分析工具，分析CPU热点
- **flamegraph**：生成火焰图，可视化性能瓶颈
- **cargo bench**：基准测试，测量代码执行时间
- **valgrind**：内存分析，检测内存泄漏

## 常见优化策略

### 所有权与借用

```rust
// 低效：频繁克隆
fn process(data: Vec<u8>) {
    let cloned = data.clone(); // 不必要之克隆
    // ...
}

// 高效：用引用
fn process(data: &[u8]) {
    // 直接用引用
}
```

### 内存分配

- 预分配容量：用`with_capacity`预分配Vec、String等
- 重用内存：复用已分配之缓冲区
- 避小对象分配：用数组或固定大小结构体

### 并发优化

- 用`Rayon`行数据并行处理
- 用`crossbeam`行无锁编程
- 用`tokio`行异步I/O

### 编译器优化

- 启LTO（链接时优化）
- 用`#[inline]`属性内联关键函数
- 用`target-cpu=native`针对本机CPU优化

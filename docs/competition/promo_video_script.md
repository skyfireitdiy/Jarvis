# Jarvis 产品首页宣传视频 · 分镜脚本

> **用途**：产品首页 Hero 区宣传片（官网首屏 / 开源仓库首页）
> **交付对象**：剪辑师（照着下面这张表即可开工）

> **比例**：16:9（1920×1080）｜ **声音**：AI 配音旁白 + 中文硬字幕 ｜ **时长**：约 95 秒（26 个镜头）
> **内容边界**：**仅介绍产品能力**，不含竞赛成绩、企业合作、社区数据、路线图等外围内容。

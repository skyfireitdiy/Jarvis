# 用户视角功能缺口 TODO

> 版本：1.0
> 日期：2026-09-22
> 状态：待评估
> 来源：从普通用户使用路径出发，对前端（`src/jarvis/jarvis_service/frontend/src/`）与文档现状的静态排查
> 说明：Jarvis 功能面已相当完整（多 Agent 编排、符号级理解、多用户 ACL、分布式节点、浏览器扩展、定时任务、方法论沉淀等均已落地）。本清单聚焦**真实使用路径上会让人卡住或体验断裂**的缺口，而非"缺大功能"。

---

## 1. 上手与求助路径

### 1.1 前端无任何"帮助 / 文档"入口

- **现状**：全前端搜索 `帮助|文档|FAQ` 仅命中两处 CSS 注释；`docs/用户手册/` 下已有 100+ 篇文档，但前端无链接入口，用户不知道这些文档存在。
- **影响**：新用户遇到问题只能靠一次性新手引导或命令面板搜索。
- **建议**：命令面板增加"打开使用文档"动作；或在右上角工具条增加 `?` 入口。
- **成本**：低（文档已存在，仅需链接）。
- **优先级**：P0

### 1.2 新手引导不可按场景重看

- **现状**：`OnboardingTour.vue` + `App.vue` 中 5 套引导（`WELCOME_TOUR_STEPS` / `LOBBY_TOUR_STEPS` / `AGENT_TOUR_STEPS` / `PANEL_TOUR_STEPS` / `SIDEBAR_TOUR_STEPS`）靠 localStorage 标记"已看过"；仅支持"重置新手引导"（全部重置）。
- **影响**：用户想重看某一具体场景（如"面板怎么用"）时，只能全部重置。
- **建议**：增加"引导目录"，可按场景单独重看。
- **优先级**：P2

### 1.3 无错误自诊断 / 反馈入口

- **现状**：无"复制诊断信息""上报问题"等入口。
- **影响**：WebSocket 连不上、Agent 起不来时，用户只能自行查看浏览器控制台。
- **建议**：增加"复制诊断信息"（连接状态、版本、最近错误日志）按钮。
- **优先级**：P2

## 2. 可观测性

### 2.1 无 token / 费用统计

- **现状**：全前端搜索 `token|费用|成本|usage|cost` 仅命中认证 token，无任何用量统计。
- **影响**：多 Agent 长任务运行时，用户完全看不到消耗，影响信任与成本控制。
- **建议**：展示按 Agent / 会话 / 时间维度的 token 用量与估算费用。
- **优先级**：P0

### 2.2 会话历史无检索

- **现状**：`SessionDialog.vue`（191 行）仅列表展示，无搜索/过滤。
- **影响**：会话一多，查找历史会话只能逐条翻。
- **建议**：按关键词 / 时间 / Agent 过滤。
- **优先级**：P1

### 2.3 无全局"运行中任务"总览

- **现状**：宠物大厅可看宠物状态，但没有一张表列出"所有 Agent 当前在跑什么任务、跑了多久、卡在哪"。
- **影响**：多 Agent 场景下难以快速定位异常。
- **建议**：增加任务总览视图（可复用已有 Agent 状态数据）。
- **优先级**：P1

## 3. 数据与配置的可带走性

### 3.1 配置无法导出 / 导入

- **现状**：`App.vue` / `SettingsModal.vue` 中搜索 `导出配置|导入配置|备份|backup` 零命中。
- **影响**：换机器、团队共享配置只能手工抄写。已有"中心 Git 仓库共享方法论/规则"，但个人配置（模型、快捷键、偏好）无一键导出。
- **建议**：增加配置导出/导入（JSON）。
- **优先级**：P1

### 3.2 聊天记录 / 会话数据无法导出

- **现状**：仅有"清空聊天记录"，无导出。
- **建议**：支持导出为 Markdown / JSON。
- **优先级**：P2

---

## 4. 移动端与可访问性

### 4.1 移动端为"能用"而非"好用"

- **现状**：移动端交互为逐个补丁式修复（如返回键、面板切换）。
- **影响**：缺系统性适配（手势、底部导航、长列表性能）。
- **建议**：做一轮系统性移动端走查与适配。
- **优先级**：P2

### 4.2 无 i18n（国际化）

- **现状**：搜索 `i18n|locale` 零命中，全中文硬编码。
- **影响**：海外用户无法使用（项目为开源项目，README 含英文，曾获开源大赛冠军）。
- **建议**：引入 i18n 框架，至少提供中英双语。
- **优先级**：P2

### 4.3 无无障碍（a11y）支持

- **现状**：无 `aria-*`，键盘焦点管理基本依赖自定义快捷键。
- **影响**：视障用户不可用。
- **建议**：补充语义化标签与焦点管理。
- **优先级**：P3

---

## 5. 协作场景

### 5.1 通知能力薄弱

- **现状**：仅 `notifyOnExit` / `notifyOnInput` 两个开关，**默认关闭**，且仅系统通知。
- **影响**：多 Agent 时容易漏掉"需要确认"的关键节点。
- **建议**：增加强提醒（需确认时）、通知历史、@提及提醒。
- **优先级**：P1

### 5.2 无"任务模板 / 常用指令"

- **现状**：每次新建 Agent 都要重新描述需求。
- **影响**：重复劳动。方法论沉淀属 Agent 侧，非用户侧快捷入口。
- **建议**：支持保存/复用用户侧任务模板。
- **优先级**：P2

## 优先级汇总

| 优先级 | 缺口                                                                                                 | 理由                                               |
| ------ | ---------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| P0     | 前端接入文档入口（1.1）                                                                              | 成本极低（文档已存在），直接解决"用户不知道有文档" |
| P0     | token / 费用统计（2.1）                                                                              | 重度用户最痛，直接影响信任与成本控制               |
| P1     | 会话历史搜索（2.2）                                                                                  | 数据一多就卡住，改动局限在 `SessionDialog.vue`     |
| P1     | 配置导出 / 导入（3.1）                                                                               | 换机 / 团队共享刚需，实现独立、风险低              |
| P1     | 运行中任务总览（2.3）                                                                                | 多 Agent 场景刚需                                  |
| P1     | 通知能力增强（5.1）                                                                                  | 关键节点易漏                                       |
| P2     | 引导目录（1.2）、错误自诊断（1.3）、聊天导出（3.2）、移动端适配（4.1）、i18n（4.2）、任务模板（5.2） | 体验完善                                           |
| P3     | 无障碍支持（4.3）                                                                                    | 长期项                                             |

# 切换不同对话风格

## 使用场景

当你希望 Jarvis 在同样的任务中使用不同的表达风格、风险提示方式和建议呈现方式时，可以通过加载不同的人格规则来切换对话风格。

## 操作步骤

1. 先准备一份描述目标风格的人格规则文件，并把它放到可被加载的规则目录中。
2. 在你的任务或会话中明确说明要切换到该人格风格，并加载对应规则。
3. 如果你想直接发起，可以使用类似表达：`接下来请使用专业严谨风格回答，重点强调风险、约束和验收标准。`
4. 在该人格规则生效后，再继续提出你的分析、编写或决策任务。
5. 观察系统输出的表达方式、结构和风险提示风格是否符合预期；如有需要，可再加载另一种人格规则做对比。

## 你会看到的提示与反馈

- 切换到不同人格后，同一类任务的回复语气和组织方式会发生变化。
- 风格的具体表现取决于你所加载的人格规则内容，例如更偏正式、结构化，或更强调风险与可验证性。
- 切换后变化主要体现在表达方式，而不是底层功能能力本身。

## 注意事项

- 这是规则系统入口，不是固定 CLI 子命令。
- 人格规则改变的是交互风格，不等于更换底层模型或功能模块。
- 如果你需要更正式或更适合汇报的输出，可以优先选择专业严谨风格。
- 如果你希望同一任务做风格对比，最好在任务目标保持不变的前提下切换人格规则。
- 风格切换更适合影响表达方式、风险提示和组织结构，不适合拿来替代明确的任务目标描述。

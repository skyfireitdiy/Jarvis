# 快速上手：从零安装到首次运行

## 使用场景

你第一次接触 Jarvis，想在一台干净的机器上把它装起来，并成功跑通第一次对话。本篇是**端到端教程**：从安装、配置、验证，到用通用 Agent 完成第一个任务，全程给出可直接复制运行的命令。

如果你只想看安装命令的速查，可先看 [快速开始](../../jarvis_book/2.快速开始.md)；本篇在其基础上补齐「装完之后怎么确认真的能用」这一段。

## 前置条件

- **操作系统**：Linux（主要支持）、Windows 10/11（WSL 或原生）。
- **Python**：3.12（一键脚本会自动安装 `uv` 并准备 Python）。
- **网络**：能访问 GitHub（或 Gitee 镜像）与所选模型平台的 API。
- **模型凭证**：一个 OpenAI 兼容或 Claude 平台的 API Base URL 与 API Key。

## 操作步骤

### 第 1 步：安装

#### 方式 A：一键安装脚本（推荐）

```bash
# GitHub（推荐）
bash -c "$(curl -fsSL https://raw.githubusercontent.com/skyfireitdiy/Jarvis/main/scripts/quick-install.sh)"

# 或使用 Gitee 镜像（国内访问更快）
bash -c "$(curl -fsSL https://gitee.com/skyfireitdiy/Jarvis/raw/main/scripts/quick-install.sh)"
```

脚本会自动：获取最新 tag 源码（浅克隆）、安装 `uv`、用 `uv tool install -e . --python 3.12` 安装 Jarvis，并可选安装 `rg`、`fd`、`fzf`、`tmux`、`tree` 等增强工具。

#### 方式 B：从源码手动安装

```bash
# 1. 克隆最新发布版本源码（请将 <latest-tag> 替换为目标 tag）
git clone --depth 1 --branch <latest-tag> https://github.com/skyfireitdiy/Jarvis.git
cd Jarvis
# 2. 将仓库内置依赖目录加入 PATH（当前仓库已内置 x86_64_linux）
export PATH="$(pwd)/src/jarvis/jarvis_data/deps/x86_64_linux:$PATH"
# 3. 使用 uv 安装项目与附加工具
uv tool install -e . --python 3.12
uv tool install playwright
uv tool install ddgr
```

#### 方式 C：Docker（免本地环境）

```bash
# 拉取最新镜像（公开，无需登录）
docker pull ghcr.io/skyfireitdiy/jarvis:latest

# 使用当前用户运行（推荐，避免文件权限问题）
docker run -it --rm \
  --user "$(id -u):$(id -g)" \
  -v $(pwd):/workspace \
  -v $HOME/.jarvis:/home/jarvis/.jarvis \
  -v $HOME/.gitconfig:/home/jarvis/.gitconfig:ro \
  -w /workspace \
  ghcr.io/skyfireitdiy/jarvis:latest
```

### 第 2 步：验证安装

```bash
# 查看版本与可用命令
jvs --help

# 查看平台与模型信息（首次运行会创建默认配置）
jpm info
```

如果命令能正常输出版本/帮助信息，说明安装成功。

### 第 3 步：配置模型

#### 推荐：交互式配置向导

```bash
jqc
```

向导会依次引导你：选择 AI 平台（OpenAI / Claude）→ 输入 API Base URL 与 API Key → 自动拉取可用模型并选择 → 配置模型组（Normal / Smart / Cheap）→ 测试连接 → 保存到 `~/.jarvis/config.yaml`。

#### 可选：手动配置

首次运行任意 `jarvis` 命令（如 `jvs`）时，若 `~/.jarvis/config.yaml` 不存在，系统会尝试启动交互式向导。按 `Ctrl+C` 退出向导后会生成默认配置文件，再手动填入凭证。

在 CI / 测试环境中可跳过向导：

```bash
export JARVIS_SKIP_INTERACTIVE_CONFIG=1
```

### 第 4 步：第一次对话

```bash
# 交互式通用 Agent
jvs
```

进入后直接输入任务，例如：

```text
用一句话介绍你自己，并列出你能调用的前 5 个工具。
```

按回车发送，观察 Agent 的思考与工具调用过程。多行输入时，用 `Ctrl + J` 提交（回车是换行）。

### 第 5 步：让 CodeAgent 改一次代码

```bash
# 进入你的一个 Git 仓库
cd /path/to/your/repo

# 交互式代码 Agent
jca
```

输入一个明确的小任务，例如：

```text
给 README.md 顶部的项目名后补一句一句话简介。
```

CodeAgent 会定位文件、修改、展示 diff 预览，并按配置执行静态检查 / 构建验证，最后生成提交。

## 你会看到的提示与反馈

- `jvs` / `jca` 启动时会打印当前加载的模型组、工具与规则数量等资源统计。
- 工具执行前若开启了确认，会弹出「将执行的工具和参数摘要」等待你确认。
- CodeAgent 修改代码后会展示增强版 diff 预览与按文件补丁摘要。
- 多行输入模式下，输入框上方会提示 `Ctrl + J` 提交。

## 注意事项

- 一键脚本优先使用 GitHub 最新 tag，失败时回退 Gitee 或默认分支。
- 使用 `uv tool install -e .` 安装后，对源码的修改会立即生效，适合开发者。
- 首次使用请妥善保管 `~/.jarvis/config.yaml`，其中含 API Key，不要提交到版本库。
- 若命令提示找不到工具或规则，参见 [常见问题](../../jarvis_book/8.常见问题.md) 的 Q5、Q6。

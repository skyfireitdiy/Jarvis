# 在平台管理器中管理和切换模型组

## 使用场景

当你已经准备好了多条 LLM 配置，想把它们组合成一套工作策略，或者想把某个模型组切换成当前默认组时，可以使用平台管理器里的模型组管理功能。

## 操作步骤

1. 打开平台管理器的模型组管理入口。
2. 根据你的目标选择对应操作：
   - 查看列表：`list`
   - 查看详情：`show`
   - 新增模型组：`add`
   - 更新模型组：`update`
   - 删除模型组：`delete`
   - 设为当前默认组：`set`
3. 如果没有直接传入模型组名称，系统会先进入交互式选择。
4. 新增模型组前，先确认配置文件中已经存在可用的 LLM 配置。
5. 新增或更新时，按提示为 `Normal`、`Cheap`、`Smart` 选择对应的 LLM 配置名称。
6. 如果你要切换当前默认组，执行 `set` 后按提示选择目标模型组即可。

## 你会看到的提示与反馈

- 如果当前没有任何模型组，系统会提示没有可用模型组。
- 如果还没有任何 LLM 配置，新增模型组时会提示：`❌ 没有可用的 LLM 配置，请先添加 LLM 配置`。
- 查看列表时，会显示模型组名称，以及它当前对应的 `normal` 配置。
- 查看详情时，会显示 `normal_llm`、`cheap_llm` 和 `smart_llm`。
- 新增成功后，会提示：`✅ 已添加模型组: ...`。
- 更新成功后，会提示：`✅ 已更新模型组: ...`。
- 删除前会要求确认；删除成功后，会提示：`✅ 已删除模型组: ...`。
- 切换成功后，会提示：`✅ 已设置当前模型组: ...`。

## 注意事项

- 模型组本身不直接填写平台和模型，而是引用已经存在的 LLM 配置。
- 至少要先准备一个可用的 `Normal` LLM 配置，模型组才能创建成功。
- 切换默认模型组后，后续依赖默认模型的功能会按新的模型组运行。

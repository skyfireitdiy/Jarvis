# 使用交互式快速配置创建模型组

## 使用场景

当你第一次接入 OpenAI 或 Claude，或者想快速生成一套可直接使用的模型配置和模型组时，可以使用交互式快速配置流程。

## 操作步骤

1. 启动快速配置入口。
2. 按提示依次输入：
   - `请输入LLM平台类型 (claude/openai):`
   - `请输入API基础URL:`
   - `请输入API密钥:`
3. 系统会尝试读取该平台的可用模型列表。
4. 如果成功拿到模型列表：
   - 先查看可用模型列表；
   - 决定是否“配置所有模型”；
   - 如果不想全部配置，就按提示输入模型序号；
   - 如果列表里没有你要的模型，也可以选择“手动输入模型名称”。
5. 接着按提示为 `Normal`、`Smart` 和 `Cheap` 三类场景分别选择模型。
6. 系统会自动测试 `Normal` 模型的 API 连通性。
7. 如果测试通过，继续输入模型组名称；如果测试失败，先决定是否仍然保存。
8. 最后按提示为实际使用到的模型填写最大 token 数，系统会把结果保存到 `~/.jarvis/config.yaml`。

## 你会看到的提示与反馈

- 启动后会先显示：`🚀 开始配置 ... 平台`。
- 拉取到模型列表后，会看到：`📋 可用模型:` 和编号列表。
- 选定模型后，会看到：`✅ 已选择 N 个模型: ...`。
- 测试连通性时，会看到：`🔍 正在测试模型 ... 的API连通性...`。
- 如果测试通过，会提示：`✅ API连通性测试通过`。
- 如果测试失败，会提示失败原因，并继续询问：`测试失败，是否仍要保存配置到文件？`
- 保存成功后，会提示已经创建模型组、已经设置默认模型组，以及：`✅ 配置已保存到 ~/.jarvis/config.yaml`。

## 注意事项

- 这个快速配置入口当前只支持 `claude` 和 `openai`。
- 如果平台模型列表读取失败，你仍然可以手动输入模型名称继续配置。
- 保存完成后，系统不仅会写入模型配置，还会自动创建模型组，并把新模型组设为当前默认组。

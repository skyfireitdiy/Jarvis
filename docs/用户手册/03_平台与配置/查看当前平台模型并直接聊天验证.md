# 查看当前平台模型并直接聊天验证

## 使用场景

当你想确认当前默认模型组到底使用了哪个平台和模型，或者想在不进入完整 Agent 流程前先快速验证模型是否能正常回复时，可以使用平台管理器的查看和聊天能力。

## 操作步骤

### 方式一：查看当前平台和模型信息

1. 打开平台管理器的信息查看入口。
2. 如果你想看当前默认组，直接执行查看命令即可。
3. 如果你想看某个指定模型组，可以额外带上 `-g` 或 `--llm-group`。
4. 提交后，查看当前平台、模型以及该平台返回的模型列表。

### 方式二：直接进入聊天验证

1. 先确认当前默认模型组可用，或者在启动命令中带上 `-g` 或 `--llm-group`。
2. 打开平台管理器的聊天入口。
3. 进入会话后，直接输入你的问题并提交。
4. 如果你想结束聊天，输入 `/bye`。

## 你会看到的提示与反馈

- 查看信息时，系统会显示默认或指定模型组对应的“平台”和“模型”。
- 如果平台可以正常返回模型列表，你会看到该平台下的候选模型清单。
- 进入聊天时，系统会提示：`✅ 连接到 ... 平台 ... 模型`。
- 聊天过程中，模型回复会以富文本形式显示。
- 输入 `/bye` 后，系统会提示：`✅ 再见!`。
- 如果平台或模型没有正确解析出来，系统会先提示参数无效，而不是直接进入聊天。

## 注意事项

- 这些能力都依赖当前默认模型组，或者依赖你在命令里显式指定的模型组。
- 如果当前配置中的平台或模型不可用，查看信息和聊天验证都可能失败。
- 聊天入口适合做快速验证，不适合替代正式的多轮任务型会话。

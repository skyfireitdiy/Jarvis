# 指定自定义配置文件

## 使用场景

当你不想使用默认配置，或者希望在某个项目、某次运行中临时切换到另一套设置时，可以在启动 Jarvis 时手动指定配置文件。

## 操作步骤

1. 先准备好你要使用的配置文件路径。
2. 启动 Jarvis 时，在命令里添加 `-f` 或 `--config`，后面跟上配置文件路径。
3. 提交命令后，系统会优先使用你这次指定的配置文件，而不是按默认位置继续查找。
4. 启动完成后，继续像平常一样输入任务或进入后续操作。

## 你会看到的提示与反馈

- 该启动参数的说明是：`自定义配置文件路径`。
- 如果你指定的配置文件存在，系统会按这一个文件继续启动。
- 如果你指定的配置文件不存在，系统不会继续沿用默认查找结果，而是进入配置处理流程。
- 如果配置内容损坏或格式错误，系统会提示配置加载失败；在部分场景下，还会继续询问你是否删除损坏文件并重新配置。

## 注意事项

- 这是一次启动级别的配置切换，适合临时试用另一套配置。
- 如果你已经显式指定了配置文件，本次运行不会再自动合并当前目录和父目录中的项目配置文件。
- 路径尽量使用你容易确认的绝对路径，能减少误用风险。

# 使用 Web 配置界面编辑配置

## 使用场景

当你不想直接手写 YAML，或者希望通过浏览器表单来编辑 Jarvis 配置时，可以启动 Web 配置界面。

## 操作步骤

1. 启动 Web 配置界面入口。
2. 如果你不传额外参数，系统会默认：
   - 使用内置的配置 Schema；
   - 把结果保存到 `~/.jarvis/config.yaml`；
   - 使用 `8080` 端口。
3. 如果你想自定义行为，可以按需要添加：
   - `--schema` 或 `-s`：指定 Schema 文件
   - `--output` 或 `-o`：指定输出配置文件
   - `--port` 或 `-p`：指定服务端口
   - `--no-browser`：启动后不自动打开浏览器
4. 启动成功后，在浏览器访问终端中显示的地址。
5. 在网页中完成配置编辑并保存。
6. 使用完成后，按 `Ctrl+C` 停止服务。

## 你会看到的提示与反馈

- 启动时会显示：`🚀 启动 Jarvis 配置工具`。
- 随后会显示当前使用的 Schema 文件、输出文件和服务端口。
- 如果 Schema 加载成功，会提示：`✓ Schema 加载成功`。
- 服务启动后，会提示：`✓ 服务已启动！`，并显示访问地址。
- 如果允许自动打开浏览器，系统会提示已经自动打开；如果自动打开失败，会提示你手动访问对应地址。
- 停止服务时，会提示：`⚠ 服务已停止`。

## 注意事项

- Web 配置界面只是配置编辑入口，不会自动替你启动新的 Jarvis 会话。
- 如果输出目录无法创建，或者 Schema 文件本身有问题，服务会在启动前直接报错。
- 修改配置后，重新启动 Jarvis，新的设置才会按当前入口生效。

# 在平台管理器中管理 LLM 配置

## 使用场景

当你已经有配置文件，想继续查看、补充、修改或删除某一条 LLM 配置时，可以使用平台管理器里的 LLM 配置管理命令。

## 操作步骤

1. 打开平台管理器的 LLM 配置管理入口。
2. 根据你的目标选择对应操作：
   - 查看列表：`list`
   - 查看详情：`show`
   - 新增配置：`add`
   - 更新配置：`update`
   - 删除配置：`delete`
3. 如果你没有在命令后直接写配置名称，系统会进入交互式选择。
4. 新增配置时，系统会依次要求你输入：
   - 平台名称
   - 模型名称
   - 最大 token 数
   - API 基础 URL
   - API 密钥
5. 更新或删除时，按提示选择目标配置并确认操作。

## 你会看到的提示与反馈

- 如果当前还没有任何 LLM 配置，列表或详情操作会提示没有可用配置。
- 查看列表时，会显示每条配置对应的“平台/模型”。
- 查看详情时，会显示平台、模型、最大 token 数，以及其他配置项。
- 新增成功后，会提示：`✅ 已添加 LLM 配置: ...`。
- 更新成功后，会提示：`✅ 已更新 LLM 配置: ...`。
- 删除前会询问确认；删除成功后，会提示：`✅ 已删除 LLM 配置: ...`。
- 如果某条 LLM 配置仍被模型组引用，系统会先给出提醒，再由你决定是否继续处理。

## 注意事项

- 平台管理器会直接读写默认配置文件 `~/.jarvis/config.yaml`。
- 删除被模型组引用的 LLM 配置前，建议先检查相关模型组是否也需要同步调整。
- 新增或修改时，平台名称、模型名称、API 基础 URL 和 API 密钥都不能留空。

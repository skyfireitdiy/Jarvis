# 启动 OpenAI 兼容接口和角色对话

## 使用场景

当你想把当前默认模型以兼容 OpenAI 的接口形式提供给外部程序，或者想先从角色配置里挑选一个角色再开始对话时，可以使用平台管理器的服务模式和角色模式。

## 操作步骤

### 方式一：启动 OpenAI 兼容接口

1. 先确认当前默认模型组已经配置完成。
2. 打开平台管理器的服务入口。
3. 按需要指定服务地址和端口；如果不指定，会使用默认主机和端口。
4. 启动后，让外部程序按该服务地址访问当前默认平台和模型。

### 方式二：从角色配置开始对话

1. 准备角色配置文件；如果不额外指定，系统默认读取 `~/.jarvis/roles.yaml`。
2. 打开平台管理器的角色入口。
3. 如果你要使用别的角色文件，在命令里通过 `--config` 或 `-c` 指定路径。
4. 提交后，系统会先列出可用角色。
5. 你可以先用交互式选择，也可以在回退输入里按编号选择角色。
6. 选中后，系统会立即按该角色开始对话。

## 你会看到的提示与反馈

- 服务模式会按当前默认平台和模型启动，不需要你再次输入平台名和模型名。
- 如果角色配置文件不存在，会提示：`❌ 角色配置文件 ... 不存在`。
- 如果角色文件格式不对或缺少角色列表，会提示：`❌ 无效的角色配置文件`。
- 角色列表会显示角色名称和说明。
- 选择成功后，会提示：`✅ 已选择角色: ...`，随后进入聊天。
- 如果你在角色选择阶段直接回车退出，系统会直接结束，而不是强制继续。

## 注意事项

- 服务模式和角色模式都依赖当前默认模型组或你显式指定的模型组已经可用。
- 角色模式读取的是角色配置文件，不是普通任务文本文件。
- 如果你只是想验证模型连通性，直接聊天入口通常更轻量；角色模式更适合测试不同角色设定下的对话效果。

# 使用新手引导快速上手

## 使用场景

当你第一次登录 Web 界面时，Jarvis 会自动弹出一份交互式新手引导，带你认识界面上的关键区域。它适合刚部署完 Jarvis、还没创建过 Agent，或者虽然连上了但不知道从哪里开始的新用户。

如果你已经熟悉界面，可以随时跳过；之后想再看一遍，也可以从命令面板重新打开。

## 操作步骤

1. 使用密码登录 Web Gateway（或使用已保存的凭证自动连接）。
2. 连接成功后约 1 秒，新手引导会自动出现，界面其余部分被压暗，当前讲解的按钮或区域会高亮。
3. 阅读气泡中的说明，点击“下一步”继续；也可以点“上一步”回看。
4. 一共 6 步，依次介绍：
   - **欢迎使用 Jarvis**：Jarvis 的核心概念——同时驱动多个 Agent 协作。
   - **宠物大厅**：没有打开任何面板时看到的大厅，每个 Agent 都是一只可拖动的宠物，双击即可打开它的对话面板。
   - **创建第一个 Agent**：顶栏的创建入口，选择节点与 Agent 类型。
   - **在面板中与 Agent 对话**：面板底部的输入框，回车发送，输出实时流式显示。
   - **命令面板**：按 `Ctrl+P`（Mac 为 `⌘+P`）或点顶栏的 `⌘` 按钮，可搜索并执行几乎所有操作。
   - **侧边栏与设置**：顶栏的 `📋` 打开 Agent 侧边栏，`⚙` 打开设置。

5. 最后一步点击“开始使用”完成引导。

### 跳过与重看

- 点击气泡右上角的 `✕`、底部的“跳过引导”，或直接按 `Esc`，都可以随时退出。
- 无论完成还是跳过，Jarvis 都会记住这次选择，之后不会再自动弹出。
- 想重看时，按 `Ctrl+P` 打开命令面板，搜索“新手引导”或“引导”“教程”“help”，回车即可重新打开。

### 无 Agent 时的空状态引导

如果当前还没有任何 Agent，宠物大厅中央会显示一块空状态卡片，包含两个按钮：

- **创建第一个 Agent**：直接在第一个在线节点上打开创建窗口。
- **查看新手引导**：重新打开这份引导。

## 你会看到的提示与反馈

- 引导出现时，被讲解的按钮或区域会有一圈青色高亮描边，其余部分被半透明遮罩压暗。
- 气泡上方显示步骤标题与进度（如 `3 / 6`），下方有一排圆点指示当前进度。
- 如果某一步要讲解的元素当前不在界面上（例如还没有打开任何 Agent 面板），该步骤会自动降级为屏幕中央的卡片，不会卡住。
- 完成引导后，右下角会弹出“引导完成，开始使用 Jarvis 吧”的成功提示。
- 在登录窗口中，密码输入框下方会提示 admin 初始密码的获取方式；登录按钮下方会提示“登录后会自动展示一次新手引导”。

## 注意事项

- 引导只是界面上的浮层，不会修改任何 Agent 状态或配置，随时退出都不会影响正在运行的任务。
- 引导使用键盘时：`Esc` 跳过，`←` / `→` 切换上一步 / 下一步。
- “已看过引导”的标记保存在浏览器本地存储中（键名 `jarvis_onboarding_done_v1`）。清除浏览器数据、更换浏览器或使用无痕窗口后，引导会再次自动展示。
- 如果你在引导展示期间登录凭证失效并回到连接弹窗，引导会自动关闭，重新登录后不会再重复弹出。
- 首次使用请务必在“设置 → 修改密码”中修改 admin 初始密码。

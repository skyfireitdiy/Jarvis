# 使用新手引导快速上手

## 使用场景

当你第一次登录 Web 界面时，Jarvis 会按场景自动弹出交互式新手引导，带你认识界面上的关键区域。它适合刚部署完 Jarvis、还没创建过 Agent，或者虽然连上了但不知道从哪里开始的新用户。

引导不是一次性弹到底的，而是**按场景拆分**：进入某个场景且该场景的引导还没看过时，才会自动出现。如果你已经熟悉界面，可以随时跳过；之后想再看一遍，也可以从命令面板重新打开。

## 操作步骤

1. 使用密码登录 Web Gateway（或使用已保存的凭证自动连接）。
2. 连接成功后约 0.8 秒，**欢迎引导**会自动出现，界面其余部分被压暗，当前讲解的按钮或区域会高亮。
3. 阅读气泡中的说明，点击“下一步”继续；也可以点“上一步”回看。
4. 引导共分 5 个场景，各自在自己对应的时机触发；每个场景的最后一步点击“开始使用”即可完成该场景引导。

| 场景       | 步骤数 | 触发时机                                                       |
| ---------- | ------ | -------------------------------------------------------------- |
| 欢迎引导   | 6 步   | 登录后自动出现，介绍 Jarvis 的定位、核心概念、工具条与命令面板 |
| 大厅引导   | 7 步   | 没有打开任何面板、停留在宠物大厅时                             |
| Agent 引导 | 4 步   | 首次创建出 Agent 之后                                          |
| 面板引导   | 5 步   | 首次打开某个 Agent 的对话面板之后                              |
| 侧边栏引导 | 4 步   | 首次打开 Agent 侧边栏之后                                      |

各场景大致会讲到：

- **欢迎引导**：Jarvis 的核心概念——同时驱动多个 Agent 协作；五个核心概念（Agent、节点、网关、宠物大厅、命令面板）；右上角工具条各入口；命令面板的分组、搜索与执行；隐藏宠物、退出登录、管理面板等更多入口；如何创建第一个 Agent 并开始对话。
- **大厅引导**：大厅仪表盘（时间、连接状态、网关地址、节点与 Agent 统计）；宠物就是 Agent（拖动、双击打开面板）；节点与拓扑；创建 Agent；一句话创建 Agent（⚡ 悬浮按钮）；宠物右键菜单；节点右键菜单。
- **Agent 引导**：Agent 状态颜色含义；Agent 侧边栏；管理单个 Agent（重命名/复制/权限管理/无损重生/删除/人工介入）；自定义分组。
- **面板引导**：在面板中对话；确认卡片；面板右键菜单；分离与关闭；自动滚动与自动朗读。
- **侧边栏引导**：Agent 列表；Agent 右键菜单；批量操作；管理分组。

### 跳过与重看

- 点击气泡右上角的 `✕`、底部的“跳过引导”，或直接按 `Esc`，都可以随时退出当前场景引导。
- 无论完成还是跳过，Jarvis 都会记住该场景已看过，之后不会再自动弹出。
- 想重看时，按 `Ctrl+P` 打开命令面板，搜索“新手引导”“引导”“教程”“help”等关键词，可执行：
  - **查看 Jarvis 介绍**：重新打开欢迎引导。
  - **查看侧边栏引导**：重新打开侧边栏引导。
  - **重置新手引导**：清除全部场景的“已看过”标记，之后进入对应场景会重新自动触发。

### 无 Agent 时的空状态引导

如果当前还没有任何 Agent，宠物大厅中央会显示一块空状态卡片，包含两个按钮：

- **创建第一个 Agent**：直接在第一个在线节点上打开创建窗口。
- **查看新手引导**：重新打开欢迎引导。

## 你会看到的提示与反馈

- 引导出现时，被讲解的按钮或区域会有一圈青色高亮描边，其余部分被半透明遮罩压暗。
- 气泡上方显示步骤标题与进度（如 `3 / 5`），下方有一排圆点指示当前进度。
- 如果某一步要讲解的元素当前不在界面上（例如还没有打开任何 Agent 面板），该步骤会自动降级为屏幕中央的卡片，不会卡住。
- 完成**欢迎引导**后，右下角会弹出“引导完成，开始使用 Jarvis 吧”的成功提示。
- 在登录窗口中，密码输入框下方会提示 admin 初始密码的获取方式；登录按钮下方会提示“登录后会自动展示一次新手引导”。

## 注意事项

- 引导只是界面上的浮层，不会修改任何 Agent 状态或配置，随时退出都不会影响正在运行的任务。
- 引导使用键盘时：`Esc` 跳过，`←` / `→` 切换上一步 / 下一步。
- “已看过引导”的标记保存在浏览器本地存储中，键名规则为 `jarvis_onboarding_{场景}_v1`（例如欢迎引导为 `jarvis_onboarding_welcome_v1`）；旧版本曾使用单一键 `jarvis_onboarding_done_v1`，现已作为欢迎引导的历史兼容标记。清除浏览器数据、更换浏览器或使用无痕窗口后，引导会再次自动展示。
- 如果你在引导展示期间登录凭证失效并回到连接弹窗，引导会自动关闭，重新登录后不会再重复弹出。
- 首次使用请务必在“设置 → 修改密码”中修改 admin 初始密码。

# 使用快捷键快速操作

## 使用场景

当你在 Web 界面中频繁切换面板、操作 Agent、打开编辑器或管理节点时，使用快捷键可以比鼠标点击更快。本页汇总了两类快捷键：

- **空格 Leader 序列**：按空格后依次输入两个字母，即可触发对应动作，适合高频操作。
- **标准双键快捷键**：类似 VS Code 的 `Ctrl+P`、`Ctrl+S` 等，适合快速打开面板或编辑器。

## 操作步骤

### 使用空格 Leader 序列

1. 在页面上按一次空格键（`Space`），进入“Leader 模式”。
2. 依次按「领域键」和「动作键」两个字母。
3. 命中后页面会执行对应动作，并自动退出 Leader 模式。

例如：按 `Space` → `a` → `f`，即可刷新 Agent 列表。

> 说明：空格 Leader 序列使用无修饰键的单字母，避免与系统或浏览器拦截的组合键冲突。输入框、编辑器或终端获得焦点时，空格键不会进入 Leader 模式。

## 你会看到的提示与反馈

- 按空格进入 Leader 模式后，页面会显示当前领域下的可选动作，方便你查看按键。
- 命中一个动作后，页面会执行该动作并退出 Leader 模式。
- 部分动作有前置条件，例如「删除当前 Agent」需要已选中 Agent，「重启所有节点」需要管理员权限；不满足条件时该动作不会生效。
- 危险操作（如删除 Agent、重启所有节点、重启网关）会弹出确认提示，需要你再次确认后才执行。

## 注意事项

- 空格 Leader 序列在输入框、在线编辑器或终端获得焦点时不会触发，避免影响正常输入。
- `Ctrl/Cmd + P`、`Ctrl/Cmd + A`、`Ctrl/Cmd + F` 在编辑器或输入框获得焦点时会让位给编辑器的原生行为（如查找、全选），不会打断你的编辑。
- 标准双键快捷键以页面实际表现为准；如果你所在环境有系统级快捷键拦截，部分组合键可能无法触发，此时可改用空格 Leader 序列。
- 本页快捷键清单与当前版本一致；如果后续版本调整了按键，请以页面命令面板中展示的快捷键为准。

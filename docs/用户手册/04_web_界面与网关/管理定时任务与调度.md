# 管理定时任务与调度

## 使用场景

当你想让 Jarvis 在某个时间点、每隔一段时间，或按 cron 表达式周期性地自动执行任务（例如定时运行脚本、定时调用某个能力）时，可以使用定时任务调度。定时任务由后端调度器统一管理，支持一次性任务和循环任务。

## 操作步骤

### 了解调度类型

创建定时任务时，需要从以下四种调度方式中选择一种：

| 调度方式   | 说明                   | 适用场景                        |
| ---------- | ---------------------- | ------------------------------- |
| `run_at`   | 在指定的时间点执行一次 | 某个固定时刻运行一次            |
| `delay`    | 延迟指定秒数后执行一次 | 相对当前时间延迟执行            |
| `interval` | 每隔固定秒数循环执行   | 周期性重复执行                  |
| `cron`     | 按 cron 表达式周期执行 | 复杂的周期调度（如每周一 9 点） |

### 使用 cron 表达式

cron 表达式采用标准 5 段格式：`分 时 日 月 周`。

| 字段 | 取值范围                 |
| ---- | ------------------------ |
| 分   | 0-59                     |
| 时   | 0-23                     |
| 日   | 1-31                     |
| 月   | 1-12                     |
| 周   | 0-7（0 与 7 均表示周日） |

支持的语法：

- `*`：任意值。
- `*/数字`：步进，例如 `*/5` 表示每 5 分钟。
- `范围`：例如 `9-17` 表示 9 到 17。
- `列表`：例如 `1,3,5` 表示 1、3、5。
- 日与周为 OR 关系（与标准 cron 一致），即日期字段或星期字段任一匹配即触发。

示例：

| cron 表达式    | 含义           |
| -------------- | -------------- |
| `0 9 * * 1`    | 每周一 9:00    |
| `*/15 * * * *` | 每 15 分钟     |
| `0 0 * * *`    | 每天 0:00      |
| `30 8 1 * *`   | 每月 1 日 8:30 |

如果 cron 表达式非法，系统会拒绝创建任务并提示错误。

### 查看定时任务

1. 在 Web 界面左侧活动栏中，点击「定时任务」图标（时钟形状）。
2. 侧边栏会列出当前已创建的定时任务，每个任务显示名称、调度类型和调度信息。
3. 定时任务页签会定时自动刷新，以展示最新状态。

### 创建或删除定时任务

定时任务的创建与删除由 Agent 直接控制，而非通过前端界面按钮操作：

- 你可以在对话中向 Agent 提出需求（例如“每 5 分钟执行一次某命令”），Agent 会调用定时任务能力来创建任务。
- 也可以让 Agent 删除或查询某个定时任务。
- 定时任务由后端调度器持久化保存，网关重启后会自动恢复。

## 你会看到的提示与反馈

- 创建任务时，如果调度参数非法（例如延迟秒数为负数、间隔秒数为 0 或负数、cron 表达式格式错误），系统会返回错误提示。
- 循环任务（`interval` 或 `cron`）会按设定持续触发；一次性任务（`run_at` 或 `delay`）触发后即完成。
- 定时任务列表是只读展示，你可以在管理侧边栏查看，但不能直接在这里修改或删除。

## 注意事项

- 定时任务由后端调度器统一管理，并持久化到本地文件；网关重启后会自动恢复已创建的任务。
- cron 表达式为 5 段格式，周字段 0 与 7 都表示周日。
- 创建或删除定时任务需要通过 Agent 完成；如果你需要精确控制任务参数，请在对话中向 Agent 说明调度方式与触发条件。

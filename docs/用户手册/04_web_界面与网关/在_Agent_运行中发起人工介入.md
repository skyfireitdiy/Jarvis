# 在 Agent 运行中发起人工介入

## 使用场景

当 Agent 仍在继续执行任务，但你想在中途主动插入干预信号，让当前运行过程尽快响应你的人工处理意图时，可以使用 Web 界面的人工介入能力。

## 操作步骤

1. 先切换到正在运行中的 Agent。
2. 使用以下任一方式发起人工介入：
   - 打开命令面板（`Ctrl+P`），搜索并选择“人工介入”动作（快捷键 `Ctrl+Alt+I`）。
   - 在非输入模式下且输入框为空时，按 `Ctrl+C` 发送人工介入信号。

3. 系统会立即把人工介入信号发给当前 Agent。
4. 之后继续观察消息区和状态变化，等待 Agent 对这次介入做出后续响应。

## 你会看到的提示与反馈

- 人工介入只对当前选中的 Agent 生效；如果当前没有选中 Agent，会提示“没有选中的 Agent”。
- 发送成功后，页面会提示“已发送中断信号”。
- 发送后，页面不会额外要求你再输入一条命令；这是一次直接的人工介入操作。
- 介入后，后续变化通常会体现在消息区输出、状态变化，或后续再次请求你输入内容。

## 注意事项

- 这不是普通文本输入，而是专门的人工干预信号。
- 人工介入只作用于当前选中的 Agent；如果你切换错了 Agent，信号会发到错误的对象上。
- 如果当前 Agent 已经完成，或当前页面没有实时连接，介入可能不会产生预期效果。
- 发送人工介入后，建议继续留意消息区和状态栏，判断是否还需要你继续补充输入或确认。

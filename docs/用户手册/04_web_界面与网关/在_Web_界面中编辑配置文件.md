# 在 Web 界面中编辑配置文件

## 使用场景

当你不想手写 `~/.jarvis/config.yaml`，而是希望在 Web 界面里通过可视化表单修改 Jarvis 配置时，可以使用「配置文件编辑」入口。它基于 JSON Schema 动态生成表单，同时提供纯文本视图，方便你在图形界面与原始文本之间切换。

## 操作步骤

1. 先确保你已经连接到 Web Gateway，并且当前账号具备 `admin:config` 权限。
2. 打开「设置」弹窗（顶部设置按钮，或快捷键 `Ctrl+Alt+,`）。
3. 在设置弹窗中找到「配置文件编辑」区域，点击「编辑配置文件」按钮。
4. 弹窗打开后会自动加载两部分内容：
   - 配置 Schema（用于生成表单）
   - 当前节点的配置文件内容
5. 弹窗顶部有两个视图标签，按需切换：
   - 「表单」：按 Schema 动态生成的字段表单，适合逐项修改。
   - 「纯文本」：以 YAML 文本方式编辑整份配置，适合批量修改或粘贴。
6. 在「表单」视图中修改字段；如果切到「纯文本」，当前表单内容会同步序列化为 YAML。
7. 修改完成后，点击「保存配置」。
8. 如果只想放弃当前修改并重新读取，点击「重新加载」。
9. 完成后点击「关闭」退出弹窗。

## 你会看到的提示与反馈

- 弹窗打开时会短暂显示「加载配置中...」，随后进入编辑界面。
- 如果加载失败，会显示错误信息，并提供「重试」按钮。
- 在「纯文本」视图中，顶部会提示：以纯文本方式编辑配置（YAML 格式），保存时会先解析校验，失败时不会写入。
- 保存成功后，会弹出「配置已保存」的提示。
- 保存失败时，弹窗内会显示具体错误信息：
  - 纯文本视图解析失败时，提示形如「纯文本解析失败：...」，此时不会写入文件。
  - 请求失败时，会显示后端返回的错误信息。
- 保存过程中，保存按钮会变为「保存中…」并处于禁用状态，避免重复提交。

## 注意事项

- 该入口需要 `admin:config` 权限；权限不足时会提示 `Permission denied: admin:config`。
- 编辑对象是当前所选节点的配置文件（默认 `~/.jarvis/config.yaml`）。在设置弹窗中选择不同节点，会对应读写该节点的配置。
- 表单视图只覆盖 Schema 中声明的字段；保存时会保留 Schema 未覆盖的顶层键，避免丢失额外配置。
- 纯文本视图使用的是轻量 YAML 处理逻辑，支持常见的标量与嵌套结构；如果你粘贴了较复杂的 YAML（例如含 `- item` 列表项或内联 `{}` / `[]` 的写法），可能解析失败，此时建议改用表单视图，或简化文本后重试。
- 保存会直接写入配置文件，请确认修改内容无误后再提交。
- 配置编辑弹窗会覆盖在设置弹窗之上；关闭配置编辑器后即可回到设置界面。

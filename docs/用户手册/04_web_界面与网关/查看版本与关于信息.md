# 查看版本与关于信息

## 使用场景

当你想确认当前 Jarvis Web Gateway 的版本、查看开源协议与作者信息，或者了解已接入的节点、后台服务（Daemon）和浏览器扩展各自运行在哪个版本时，可以使用「关于」弹窗。

## 操作步骤

### 打开「关于」弹窗

1. 在 Web 界面左侧的活动栏中，找到「关于」图标（圆形感叹号形状）。
2. 点击该图标，即可打开「关于」弹窗。
3. 再次点击同一图标，或点击弹窗右上角的关闭按钮（×），或按 `Esc` 键，可关闭弹窗。

### 查看软件信息

弹窗顶部展示以下内容：

- **软件名称**：Jarvis Web Gateway
- **版本**：前端版本；若后端版本与前端不同，会额外显示「/ 后端 <版本号>」
- **开源协议**：MIT
- **作者**：skyfire

### 查看各组件版本

弹窗按类别列出当前环境中的组件版本：

- **节点版本**：列出当前网关下的各节点及其版本号与在线状态。
- **后台服务（daemon）版本**：列出当前在线的后台服务及其版本号与所属平台。
- **浏览器扩展版本**：列出当前在线的浏览器扩展及其版本号与浏览器信息。

如果某一类当前没有在线组件，会显示对应的空态提示（如「暂无节点信息」「暂无在线后台服务」「暂无在线浏览器扩展」）。

## 你会看到的提示与反馈

- 「关于」弹窗是只读的，你只能查看信息，不能在这里修改版本或配置。
- 版本信息来自前端内置版本号，以及后端 `/api/node/status`、`/api/daemon/sessions`、`/api/browser-ext/sessions` 返回的数据。
- 只有「当前在线」的节点、后台服务或浏览器扩展会出现在对应列表中；未安装、未启动或未连接的组件不会显示。

## 注意事项

- 「关于」弹窗展示的是打开时刻的状态；如果组件在弹窗打开期间上线或下线，需要关闭后重新打开才能看到最新结果。
- 前端版本号随发布自动同步；后端版本号与前端一致时不会重复显示。

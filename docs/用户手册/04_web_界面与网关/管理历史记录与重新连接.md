# 管理历史记录与重新连接

## 使用场景

当你想查看当前浏览器里已经保存了多少历史消息、清理历史记录、修改登录密码，或者修改网关连接信息后重新连接到网关时，可以在网页设置或连接弹窗中完成这些操作。

## 操作步骤

### 查看历史记录统计

1. 点击页面顶部的“设置”按钮。
2. 在设置窗口中查看历史消息统计信息。
3. 这里会显示当前历史消息数量和占用空间。

### 清除历史记录

1. 在设置窗口中点击“清除历史记录”。
2. 根据页面提示再次确认。
3. 清理完成后，当前 Agent 的消息区和历史分页状态会同步更新。

### 修改登录密码

1. 在设置窗口的“修改密码”区域填写旧密码、新密码并再次确认。
2. 点击“修改密码”按钮提交。
3. 修改成功后，下次登录请使用新密码。

### 断开连接

1. 在设置窗口的“连接管理”区域点击“断开连接”。
2. 页面会关闭所有 WebSocket 连接并刷新页面。

### 修改网关连接信息并重新连接

网关地址、用户名和连接密码是在**连接弹窗**中填写的，不在设置弹窗中：

1. 断开当前连接，或直接刷新页面回到连接弹窗。
2. 在连接弹窗中修改网关地址、用户名、密码。
3. 点击“连接”按新信息重新建立连接。
4. 如果连接成功，页面继续进入正常使用状态；如果失败，会重新显示连接窗口或错误提示。

## 你会看到的提示与反馈

- 设置窗口标题为“设置”。
- 历史消息区域会显示：
  - 历史消息数量
  - 存储空间

- 如果当前没有历史记录，“清除历史记录”按钮会不可用。
- 清除历史记录前会有确认步骤，因为这是不可撤销操作。
- 修改密码成功后会有提示；密码修改不影响当前已建立的连接。
- 断开连接后，顶部连接状态会变为“未连接”，页面会刷新。

## 注意事项

- 历史记录保存在当前浏览器本地，不是服务端全局历史。
- 清除历史记录是不可撤销操作，确认前请先判断是否还需要保留当前浏览记录。
- 修改登录密码在设置弹窗中进行；修改网关地址、用户名或连接密码需在连接弹窗中操作并重新连接。
- 如果重新连接失败，优先检查网关地址格式、网关服务是否启动，以及密码是否正确。

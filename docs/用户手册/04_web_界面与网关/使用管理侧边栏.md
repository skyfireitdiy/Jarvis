# 使用管理侧边栏

## 使用场景

当你想快速查看当前系统里有哪些定时任务、哪些后台服务（Daemon）或浏览器扩展已经接入并上报了能力清单时，可以使用管理侧边栏。它提供只读的概览，方便你了解当前环境的运行状态。

## 操作步骤

### 打开管理侧边栏

1. 在 Web 界面左侧的活动栏中，找到「增强能力清单」图标（网格形状）和「定时任务」图标（时钟形状）。
2. 点击其中一个图标，即可在左侧打开对应的管理侧边栏页签。
3. 再次点击同一图标，可收起侧边栏。

### 查看定时任务

1. 点击活动栏中的「定时任务」图标（时钟形状）。
2. 侧边栏会列出当前已创建的定时任务。
3. 每个任务会显示任务名称、调度类型和调度信息（例如指定的运行时间、延迟秒数、间隔秒数或 cron 表达式）。
4. 如果没有定时任务，会显示「暂无定时任务」的提示。

### 查看增强能力清单

1. 点击活动栏中的「增强能力清单」图标（网格形状）。
2. 侧边栏会按类别展示已接入的能力：
   - **Daemon 能力**：列出当前在线的后台服务（Daemon）会话及其上报的能力。每个能力可展开查看名称、描述、参数和所属平台。
   - **浏览器扩展能力**：列出当前在线的浏览器扩展会话及其上报的能力，同样可展开查看详情。
   - **自定义脚本**：列出已安装的脚本（网关脚本库），并显示脚本数量。
3. 如果某个会话没有上报能力，会显示「该会话未注册能力」或「该扩展未上报能力」。
4. 如果当前没有任何在线的 Daemon、扩展或脚本，会显示「暂无可用能力」。

### 展开或折叠能力详情

1. 在能力清单中，点击某个能力条目左侧的箭头（▶/▼）。
2. 展开后可以查看该能力的描述、参数 JSON 和所属平台。
3. 再次点击箭头可折叠详情。

## 你会看到的提示与反馈

- 管理侧边栏是只读的，你只能查看和展开/折叠内容，不能在这里修改或删除定时任务、能力或脚本。
- 「增强能力清单」页签提供手动刷新按钮，用于重新拉取最新的能力清单。
- 定时任务页签会定时自动刷新，以便展示最新的任务状态。
- Daemon 能力与浏览器扩展能力的展示格式一致（名称、描述、参数、平台），均由对方动态上报，前端无需针对单个能力单独适配。

## 注意事项

- 管理侧边栏展示的是「当前在线」的会话与能力；如果某个 Daemon 或浏览器扩展未安装、未启动或未连接，就不会出现在清单中。
- 定时任务由后端调度器统一管理，管理侧边栏只负责展示；创建或删除定时任务需要通过其他入口（如管理面板或 API）完成。
- 能力清单只反映上报时刻的状态，新增或移除能力后需要刷新才能看到最新结果。

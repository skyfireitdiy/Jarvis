# 使用密码登录 Web Gateway

## 使用场景

Jarvis Web Gateway 采用**用户名 + 密码**的账号体系进行认证。连接时你需要先在网页中输入用户名和密码，换取访问凭证，之后才能正常访问 Agent 列表、文件、终端和其他 Web 功能。

## 操作步骤

1. 先确保已经拥有可登录的账号（首次启动会自动创建 `admin` 账号，初始密码来自环境变量 `JARVIS_ADMIN_PASSWORD`，详见「配置网关认证密码与未设置密码时的访问策略」）。
2. 在浏览器中打开 Web 界面，进入“连接到 Jarvis”窗口。
3. 在“用户名”输入框中填写用户名（首次使用填 `admin`）。
4. 在“密码”输入框中填写正确密码。
5. 在“网关地址”输入框中填写 Web Gateway 地址。
6. 点击“连接”。
7. 页面会先使用你输入的用户名和密码进行登录，再继续建立后续连接。
8. 登录成功后，页面会进入已连接状态，你可以继续使用其他网页功能。

## 你会看到的提示与反馈

- 如果登录成功，页面会继续完成连接流程，并自动关闭连接弹窗。
- 登录成功后，密码输入框中的内容会被自动清空。
- 如果用户名或密码错误、登录失败，连接窗口中会显示失败原因，而不会进入已连接状态。
- 登录成功后，后续接口和连接会自动带上当前访问凭证。

## 注意事项

- 这个密码不是每次发送操作时重复输入，而是在连接前先登录一次。
- 登录成功后，访问凭证只保存在当前页面运行期间；如果你刷新页面或重新打开页面，通常需要重新登录。
- 用户名默认是 `admin`；如果你在「管理 → 用户管理」中创建了其他用户，也可以用对应用户名登录。
- 如果你已经连接成功，但后续凭证失效或网关重启，页面可能重新回到连接弹窗，需要再次登录。

# 打开设置并管理连接、历史记录与配置备份

## 使用场景

当你已经进入 Web 界面，想修改登录密码、断开连接、查看并清除当前浏览器里保存的历史记录，或者把某个节点的配置导出备份、从备份文件恢复时，可以使用设置弹窗。

## 操作步骤

1. 在 Web 界面中打开“设置”弹窗。
2. 在弹窗里按需查看或修改以下内容：
   - “修改密码”区域（修改登录密码）
   - 历史消息数量和存储空间信息
   - “断开连接”按钮（关闭所有 WebSocket 连接并刷新页面）
   - 其他界面偏好开关（免登录、通知、隐藏工作目录、节点显示名等）

3. 如果你要清空当前保存的历史记录，点击“清除历史记录”。
4. 如果你需要备份或恢复某个节点的配置，使用“配置备份与恢复”区域：
   - **导出配置**：先在下拉框里选择目标节点，再点击“导出配置”，系统会拉取该节点的当前配置并下载为一个 JSON 文件。
   - **导入配置**：先在下拉框里选择目标节点，再点击“导入配置”，选择之前导出的 JSON 备份文件，系统会校验格式并把配置应用到该节点。

5. 如果你需要修改网关地址、用户名或连接密码，请在**连接弹窗**中操作并重新连接（这些信息不在设置弹窗中）。
6. 如果暂时不处理，点击“关闭”或右上角关闭按钮离开设置弹窗。

## 你会看到的提示与反馈

- 设置弹窗标题显示为“设置”。
- 历史消息区域会显示“历史消息数量”和“存储空间”。
- 当本地没有历史记录时，“清除历史记录”按钮会处于不可用状态。
- “连接管理”区域显示“断开连接”按钮，并提示会断开所有 WebSocket 连接并刷新页面。
- “配置备份与恢复”区域会显示“导出配置”和“导入配置”两个按钮，以及一个节点下拉框。
- 导出成功后，浏览器会下载一个 `jarvis-config-节点名-日期.json` 文件。
- 导入成功后，会提示已导入的配置项数量；导入前系统会自动备份现有配置。

## 注意事项

- 修改登录密码在设置弹窗中完成；修改网关地址、用户名或连接密码需在连接弹窗中操作并重新连接。
- “断开连接”会关闭所有 WebSocket 连接并刷新页面，请确认后再操作。
- 历史记录统计和清理面向当前浏览器中保存的数据；更换浏览器或设备后，你看到的历史数量可能不同。
- 配置导出/导入需要 `admin:config` 权限；如果没有该权限，操作会失败并提示权限不足。
- 导入配置会覆盖目标节点上对应的配置项；导入前系统会自动把现有配置备份一份，以便需要时回退。
- 导入前请确认选择的 JSON 文件格式正确（应为配置对象），否则导入会被拒绝。
